## C1 核心论点可攻击性（每论点 1 条，共 8 条）

### [核心] 三方互构生态（替代「压制—反抗」二元框架） — 可攻击性：中高
- **最强反方观点**：「三方互构」是概念堆砌——你一边在引言声明「不做强因果推定、呈现为互动/共构关系」，一边在结论写「三者互为因果，而非线性阶段」。「互为因果」就是强因果断言，与你自己的方法声明自相矛盾。到底是不是因果？是，则你的截面证据撑不住；不是，则「互为因果」只是修辞。
- **你的论据能否回应**：否。引言「不做强因果推定」与结论「三者互为因果」未统一，「互为因果」四字未加任何限定。
- **建议**：**加固**（低成本）——结论段「三者互为因果」改为「三者相互强化、相互构成（机制性互构，非因果推定）」，或在摘要/结论各加一次「本文以机制共构而非因果推定呈现」。

### [分1] #MeToo 破晓 = 连结性行动正当化跃迁 — 可攻击性：低

- **论据能否回应**：能。分1 有 L01/L02/L03/L04/L05 + D05/D08/D09/D10 + C01/C02 三角全覆盖，证据最厚。
- **建议**：**接受脆弱**（无需处理）。

### [分2] 兴起形态 = 低调话语政治，非组织化 — 可攻击性：中
- **最强反方观点**：「非组织化」是断言不是结论——你凭什么说「缺乏组织」？你测过组织化程度吗？正文自身也承认「缺乏系统量化数据」。
- **论据能否回应**：部分能。第一节末已主动声明「这一判断的局限在于……缺乏系统量化数据，只能基于既有案例与文献作定性判断」——防御到位，但定性本身仍是软断言。
- **建议**：**接受脆弱**（已自我声明局限，属理论/案例论文可接受的定性判断）。

### [分3] 污名化双向循环（真/伪女权框架 + 内部标签被收编） — 可攻击性：中
- **最强反方观点**：平台/时段错位——你论证「微博污名化双向循环」，却以 L07（**知乎** 4440 条，约 2016–2020）为骨干实证，再拼 C03（微博 2020）、L09（微博超话 2023）。知乎的「真/伪女权」框架不能直接迁移为微博机制，语料年代与平台都错位。
- **论据能否回应**：否。第二节把 L07（知乎）+ C03/L09（微博）无缝拼成同一「双向循环」，未加跨平台/跨时段过渡。

### [分4] 民族主义话术 = 污名化政治化杠杆 — 可攻击性：中高

### [分5] 极化放大机制（镜像对抗 + 商业反噬） — 可攻击性：中高

- **建议**：**加固**——「商业杀伤力」降为「商业层面的可见反噬效应」；「可重复模式」降为「反复出现的应对模式」；并补一句替代解释「下架/致歉亦可能是公关避险而非认同抵制」。

- **论据能否回应**：部分能。第四节末尾「反方立场与回应」回应了三点，但重点攻击方向 2 仍有残留——见下 C2 薄弱环节 1。

### [分7] 理论框架本土化修正 — 可攻击性：高
- **最强反方观点**（重点攻击方向 4）：用 **C09 高铁卫生巾单一案例**支撑「体制内协商」这一**理论概括**，是以偏概全 + 概念偷换。高铁卫生巾是**低政治化的民生服务诉求**（「买不到卫生巾」），不是女权政治诉求；把它当「女权主义的体制内协商」样本，是把「服务性、可个体化满足的诉求」偷换为「女权表达」。案例卡 C09 甚至明确写着「本案**未出现**『女拳/境外势力』式污名标签」——它恰恰是**低对抗度的例外**，不是通例。
- **论据能否回应**：否。正文第五节把 C09 作为「体制内协商」的「可核验正面样本」，未标注其「低对抗度/服务型/单一案例」的三重边界。
- **建议**：**加固**（优先）——明确 C09 是「低对抗度服务型诉求」的特殊样本，把「体制内协商」限定为「存在协商增量的**可能性**（边界：可个体化满足的服务诉求可被吸收，政治化诉求走治理收缩）」；或**接受脆弱**（承认单一案例，弱化理论概括力度）。
