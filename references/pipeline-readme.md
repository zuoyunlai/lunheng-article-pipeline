# 论衡（lunheng-article-pipeline）— 通用深度长文多 Agent 流水线 运行手册

> **定位**：论衡是**通用深度长文引擎**，不只用于公众号，而是可产出**学术论文、商业评论、行业分析、公众号深度长文**等各类深度长文。学术论文用 `[Lxx]/[Dxx]` 编号引用；公众号/商业评论用内联（机构，年份）引用（M 门内联引用分支）。

> 使用方式：主控 Agent（论衡）按本文档派发任务。角色定义见 `agents/`，模板见 `templates/`。

## 🚫 不适用场景（边界明示）

论衡是「论文/深度文章」**写作流水线**，**擅长主动检索已发布证据 + 整合主人投喂的证据**。

> **拆分**（第三方审查建议 #2 文档冗余）：完整「论衡能/不能主动采集」段详见 [`../SKILL.md`](../SKILL.md) §「边界与轻量化建议」（SKILL.md L127 起），本文件不重复维护（避免双形式同步漂移，教训 #269）。

**判断口诀**：问「这个证据是**已发布**的数据 / 文献 / 案例吗」——是，论衡主动采集；不是（是一手原始数据 / 自己拍的素材 / 自己跑的计算），主人投喂后再用。

   - 实战教训（教训 #262）：deepseek-v4-pro：推理/分析默认，但有过超时历史
   - 实战教训（教训 #126）：minimax-M3：推理/分析 fallback，但近期 T3 三连超时主要责任方
   - 实战教训（教训 #119）：claude-opus-5：审计顶配（T7 审计员主模型），但成本高 + 有 kkaiapi 接口静默无响应前科

## 模型配置与更换指南

> **背景**（主人 2026-08-22 指出）：operations.md 引用「模型配置与更换指南」段，但 v2.3.0 重构时 TOC 加入了三个子标题（`三层模型配置`/`更换的自由、途径、权限`/`能力分层原则`），**正文未补**——造成文档漂移（教训 #269，双形式同步漂移反模式）。本节为 v2.3.10 补全。

### 三层模型配置（从外到内）

v2.3.13 起模型不再硬编码，模型解析分**三层**（从唯一真源到兑底兜底）：

1. **SKILL.md 模型分工表**（能力档 + 候选池，**唯一真源**）
   - 检索=便宜快 / 分析写作=强推理 / 批判审计=顶配 / 主控=稳定路由
   - 每个能力档的候选池按优先级排列，换系统/换模型改这一处即可

2. **Phase 0 模型自检**（运行时映射）
   - 主控启动扫宿主可见模型元数据（`session_status` 等只读工具），每个能力档从候选池选第一个可用模型
   - 顶配档候选池全不可用 → 显式告知主人，禁止静默降级

3. **openclaw.json 模型**（仅兑底兜底，非硬配置；属宿主侧配置，论衡 agent 不读不写）
   - `agents.list[].model.primary + fallbacks` 仅作 Phase 0 自检失败时的最后兜底
   - 不再需要为论衡单独建 agent 或手动配模型

### 更换的自由、途径、权限

| 层面 | 谁能改 | 怎么改 | 生效时机 |
|---|---|---|---|
| OpenClaw 宿主配置（**宿主侧，非本技能写入范围**）| 主人（自己在宿主侧手动 edit `openclaw.json` 或用 gateway 工具）| 属宿主运维操作：**论衡 agent 不读、不写、不修改宿主配置**；需 backup 后改，gateway 重启生效 | 重启后 |
| 角色卡推荐模型 | 主人 / 主控（经主人同意） | edit 角色卡顶部；版本戳同步由维护者手工完成（净化版无脚本） | 下一轮会话 |
| 本轮可用模型 | 主控在 status.md 顶部填 | write status.md 头部「本轮可用模型」表 | 即时生效 |

**主人的自由度**：
- ✅ 任意层都可改，无需经过论衡批准
- ✅ OpenClaw 兼容的任何模型都可接入（含 Ollama 本地）
- ✅ fallback 顺序可自由调整
- ⚠️ 改完需**重跑论衡首单测试**，验证模型组合不超时/不崩

### 模型能力抽象 + 自检 + 预算闸门

> **背景**：v2.3.12 前模型名硬编码在角色卡/SKILL.md，换系统即失效；且主控无「余额不足」预检，claude-opus-5 余额不足时顶配审计**静默降级**（本机测试 T6/T7 全兑底 minimax-m3，A 级抽验仅 17%）。

- **能力抽象（P0-2）**：模型名 → **能力需求 + 候选池**（检索=便宜快 / 分析写作=强推理 / 批判审计=顶配 / 主控=稳定路由），候选池见 SKILL.md 模型分工表。
- **Phase 0 模型自检（P0-3）**：主控启动时扫宿主可见模型元数据（`session_status` 等只读工具，非 shell 命令），每个能力档从候选池按优先级选第一个可用模型，写入 status.md「本轮可用模型」表；顶配档候选池全不可用 → **显式告知主人**「本机无顶配审计模型，审计/批判深度将降级，是否继续」。
- **预算闸门（P0-1）**：派发 T6/T7 前查顶配模型余额，< $0.1 直接走候选池下一档并告知主人深度降级；同一项目已发现余额不足 → 后续顶配角色直接降级（不重复试错）。

### 能力分层原则（换模型时遵循）

> **v2.3.12 P0-2 升级**：模型名不再硬编码，抽象为「**能力档 + 候选池**」——角色卡只写能力需求，具体模型由主控 Phase 0 自检后按本机可用模型池映射（候选池见 SKILL.md 模型分工表）。下表「候选池」= **本机默认映射示例（非硬编码）**，换系统/换模型按候选池自动适配。

按角色能力需求分层选模型，**避免「T7 审计用便宜快模型」「T1 检索用顶配」错配**：

| 能力档 | 角色 | 能力需求 | 候选池 | 错配后果 |
|---|---|---|---|---|
| 检索 | **T1/T2/T3** | 便宜快（抽取+分类） | 见 SKILL.md 模型分工表 | 用顶配 = 浪费 + 慢；用太弱 = 信息丢失 |
| 分析写作 | **T4/T5** | 强推理 | 见 SKILL.md 模型分工表 | 用 flash = 大纲粗糙 / 文章失味 |
| 批判审计 | **T6/T7** | **顶配防漏判** | 见 SKILL.md 模型分工表 | 用弱模型兑底 = 批判无刃 / 审计降级 |
| 主控 | **T0** | 稳定路由 | 见 SKILL.md 模型分工表 | 主控崩 = 全流水线停 |

**核心原则**：
- **审计顶配不省**：T7 是最后一道防线，论文质量全压这——宁可其他地方慢
- **检索不奢侈**：T1/T2/T3 是流水线批量检索，便宜快模型够用
- **写手分场景**：内联引用 / 学术编号 = deepseek-v4-pro；公众号短文 = flash 够
- **本地 Ollama 可用**：涉敏 / 零外发场景用 gemma4:31b / qwen3-coder:30b

**见** `pipeline/operations.md` 成本与模型段（示例表与 fallback 链）

### 图位编号规则（教训 #157）

**图位编号 = 章节出现顺序，不是任意编号**：

1. Phase 2.5 拍板时，**图位标题先留空**，只拍板图位数量 N（如 N=3）
2. T5 写手按章节出现顺序编号：[图1] → [图2] → [图3]（**不允许断号**）
3. **不允许 [图1][图3][图4] 出现**——这是 bug，不是图位缺失
4. 主控 Phase 4.5 SVG 生成时：
   - 先 grep `\[图N\]` 全集，按章节顺序排列
   - 章节内出现顺序 = SVG 文件命名顺序
5. T7 审计员 P1 检查 `[图N：标题]` 出现次数 ≥ 拍板图位数量 + 编号连续

**实战背景**：v3 正文出现 [图1][图3][图4] 断号 = 缺编号规则约束。T5 写手按拍板数量拍，但编号任意。

### 先行者文献「本文差异化」段（教训 #171，主人反馈）

**每条 [先xx] 文献后必加「本文差异化：」段**（主人在 Phase 0 拍板是否加每条 vs 仅主论点）：

```
## 先行者文献

[先05] 各律师事务所. 高净值人士非婚生子女 / 家族财富传承 / 王思聪私生子等实务分析[EB/OL]. 北京嘉浮/上海君悦/天达共和等, 2025-2026. https://javy-lawyers.com/news/dongtai/1803715749257166849.html

本文差异化：本文是各律师事务所 2025-2026 实务观点的延伸——将"实务对冲工具"延伸到"法理+历史+国际视野"的综合论证，差异在于证明"财产外流风险"有合法对冲工具（保险/信托/婚内财产协议/撤销赠与/必留份/举证倒置）且无须减损非婚生子女份额；加入日本 2013 司法级证伪与 CRC Art. 2 国际法视角。
```

**「本文差异化」段必含 3 要素**：
① **本文延伸** — 站在该先行者的哪个角度延展（不是重复）
② **差异在于** — 与该先行者的关键不同（视角/范围/数据/结论）
③ **新贡献** — 加了哪些先行者没有的内容（数据/反驳/国际视野/历史纵深/跨学科）

**为什么必加**（主人反馈）：v2.5.4 [先xx] 仅呈现原文 → 读者看不出本文增量价值 → 原创性保证仅抽象有、具体无。v2.5.5 后 T5 必加。
