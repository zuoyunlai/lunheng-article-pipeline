# G14 中文 AI 痕迹深度检测闸

> **版本**：v2.6.3（2026-09-06）
> **性质**：闸门（Gate），LLM 推理判定（规则硬性，非机器执行）
> **位置**：`t7_5_integrity → g14_style_gate → phase4_4_figures`（别名「Phase 4.4 前置（G14 风格闸）」）—— **定稿前的最后一道闸**
> **触发次数**：**全流程只审一次、不再复检**（`rerun_after_report: false`；`audit_revision.after_each` 的 `rerun_g14_if_enabled` 已删）
> **适用性（非可选）**：由 Phase 0「目标语言」字段**客观决定**（`condition: target_language_includes_zh`）——含中文 → 必跑；纯外语 → `n/a`（客观不适用，非「关闭」）
> **执行前提**：`precondition: 已可定稿（前置修订已收敛）` —— 前置修订尚未收敛时**不执行**本闸
> **失败后果**：**3-4 类 ⚠️ Warning → 主控暂停呈报（3 选 1，不默认自动继续）**；5+ 类 ❌ Fail → 触发 `t5_style_revision`（T5 最后一次**仅风格层**修订）→ 进 Phase 4.4（**不重跑 G14**）

## 一、设计哲学

论衡从 v2.3.13 的「AI 使用披露」（透明）+「G13 AI 使用披露」（审计）演进到 v2.4.0 的「G14 中文 AI 痕迹深度检测」——**不是检测器（GPTZero 类），是论衡自己的「中文学术话语风格指南」+ 检测算法**。

**核心承诺**：
- **风格净化，非隐瞒**：G14 的目标是「去 AI 腔 + 提升中文学术话语可读性 + 贴近主人个人风格」，**不是「让 AI 痕迹不被检测到」**——G13 AI 使用披露照常在交付说明声明「本文由 AI 辅助生成」，**不隐瞒 AI 身份**
- **诚实透明**：G13 AI 使用披露照常在交付说明声明（不试图隐瞒 AI 痕迹）；G14 与 G13 互补不重叠（前者声明 + 后者净化）
- **中文特化**：所有检测维度针对**中文学术话语**，不是英文模式直接套用
- **适用规则（按 Phase 0「目标语言」字段客观适用，非可选 —— 本修订起定案）**：G14 **不再是可选功能**（原「Phase 0 显式勾选启用」与 `g14_opt_in` 已删除）。是否适用由任务简报「目标语言」字段**客观决定**：
  - **必跑**（`enabled`）：目标语言**含中文**（中文 / 中英混）→ 必跑（`condition: target_language_includes_zh`）
  - **客观不适用**（`n/a`）：目标语言为**纯外语**（English / 其他非中文）→ 不跑 G14（**客观不适用，非「关闭」**，无需披露）
  - **降级自检**（`selfcheck`）：适用且属轻量档（**2000-3000 字**，口径真源 = `字数判定表.md`）走内置「G14 自检」（不 spawn 独立 checker）
  - **主人豁免（窄口）**（`exempted_by_owner`）：主人**显式要求**关闭 → 全项目不跑，且**必须在 `final/交付说明.md` 披露**

## 二、检测维度（8 类）

| 类别 | 检测点 | 阈值 | 借鉴来源 |
|------|-------|-----|---------|
| **G14-A 学术模板语** | 「综上所述/笔者认为/本文认为/值得关注的是/不容忽视/在新时代背景下/具有重要的理论与现实意义」 | 任一模板出现 ≥3 次 | chinese-writing 7.4 |
| **G14-B 句式同质化** | 连续 3 段同句式起头（如「首先...其次...最后...」「不仅...而且...」） | 同模板 ≥2 次连续段 | 论衡自有 |
| **G14-C 学术套话高频** | 「赋能/抓手/底层逻辑/范式/迭代/路径」每段 ≥1 次 | 全文 ≥5 处 | humanizer-zh |
| **G14-D 破折号滥用** | **全文 >8 处**，或每段破折号 ≥2 处且 ≥5 段，或破折号总字数占比 >3% | 全文 ≥5 段 | humanizer-zh |
| **G14-E 三项排比** | 全文 ≥3 处「A/B/C」式排比 | 全文 ≥3 处 | humanizer-zh |
| **G14-F 人称错位** | 学术论文滥用第一人称「我」超过全文1% | 「我」字频 > 1% | 论衡自有（中文规范）|
| **G14-G 个人辨识度缺失** | LLM 判定：本文与10 篇同主题论文风格相似度 >80% | LLM 自评判定 | 论衡自有 |
| **G14-H 党报话语堆砌** | 政治学科特化：「重要讲话精神/重要指示/根本遵循」过多 | 全文 ≥3 处 | 论衡自有 |

> 🔍 **G14-B 口径固定（v2.12.32 新增，回应实测 P1——口径分叉）**：实测中**同一稿**因「连续段」读法不同得到 **Warning（3 类）** 与 **Pass（0 类）** 两个结论，末轮争议全落在口径上。**口径须在 Phase 0 固定并写入任务简报**（`G14口径: 严格|宽松`）：
> - **严格（默认）**：命中口径 = ① **相邻正文段**（不含标题行）连续 ≥3 段同句式起头，**或** ② **小节开门段同构**（连续 ≥2 个小节的首段用同一句式起头）——二者任一即算 B 类命中。
> - **宽松（主人显式选择）**：仅计 ①，**不计**小节开门段同构。
> - 未在 Phase 0 固定 ⇒ **按严格口径判定**；G14/T7 报告头部须写明所用口径（`g14_scope: strict|lax`），避免末轮再争议。

## 三、判定规则

**单条命中**：每类单独计算，每类内部阈值独立判定。

**整体判定**（v2.12.49 M-4 修）：**取 `max(类数档判定, 单类严重度档判定)`，二者取严**：
- 命中 0-2 类 + 任一类实测 < 阈值 3 倍 → ✅ Pass（轻微 AI 味，可接受）
- 命中 3-4 类 / 或任一类实测 ≥ 阈值 **3 倍** → ⚠️ Warning（**不自动修订**：主控暂停 → 呈报 3 选 1；选 B 才触发 `t5_style_revision` 风格修订 1 次）
- 命中 5+ 类 / 或任一类实测 ≥ 阈值 **5 倍** → ❌ Fail（触发 `t5_style_revision` —— T5 最后一次**仅风格层**修订；**G14 不重跑**）

**单类严重度档（v2.12.49 M-4 新增）**：

| 单类实测 / 阈值 | 档位 | 判定 |
|---|---|---|
| < 1x | 正常 | 不计入严重度 |
| 1x-3x | 偏高 | 类数档覆盖 |
| **3x-5x** | **超阈** | **Warning**（主控必须列在 `severe_single_class` 报告字段） |
| **> 5x** | **严重** | **Fail**（即数即判，无论类数） |

**报告头必填字段**（v2.12.49 M-4 必填，防「超阈 11.5 倍被类数 0 洗成 Pass」同型漏检）：
```yaml
g14_report_header:
  hit_class_count: <N>          # 命中类数
  hit_class_names: [G14-A, ...]  # 命中类名列表
  severe_single_class:           # 严重度单类（可选，多于命中；未命中则为空列表）
    - {name: G14-D, measured: <N>, threshold: <M>, ratio: <R>}
  final_verdict: <pass|warning|fail>   # max(类数档, 严重度档)
  max_band_basis: <class_count|single_severity>  # 哪个档起决定作用
```

**反面实例**（修 M-4）：**超阈 11.5 倍但类数 0 → 旧口径判 Pass**（实测见个体化命题报告）。**新口径下 = max(类数档=Pass, 严重度档=11.5x>5x=Fail) ⇒ Fail**。

**例外豁免**（主人可显式要求关闭）：
- 「本文认为」/「笔者认为」等学术模板语在**引言/结论**段可豁免（学术规范要求）
- **结构必写段豁免（#2）**：「本文认为/本文提出」在先行者文献「本文差异化」段 / AI 使用声明段 / 摘要限定语 / 主人洞察理论贡献段可豁免（论衡模板强制要求书写；豁免清单同源见写手卡「元叙事清理清单」§ 自指式豁免段）
- 破折号在**正文叙述**段豁免（仅检查论点段）

## 四、触发流程

**适用性**：G14 是**客观适用**、非可选的闸（详见 §一）。适用/不适用由 Phase 0「目标语言」字段决定 —— **含中文 → 必跑**；**纯外语 → `n/a`**（客观不适用，非「关闭」）。报告头须绑定 `draft_id` / `draft_version`。

**触发次数与位置**：**全流程只审一次、不再复检**。位置 = `t7_5_integrity → g14_style_gate → phase4_4_figures`（别名「Phase 4.4 前置（G14 风格闸）」）—— **定稿前的最后一道闸**。`rerun_after_report: false`；`audit_revision.after_each` 中的 `rerun_g14_if_enabled` 已删除，任何一轮修订都不再触发 G14 重跑。

**执行前提**：`precondition: 已可定稿（前置修订已收敛）` —— 前置修订尚未收敛（`audit_revision` 未退出 / 仍有未决 P0·P1 修订项 / 尚不能定稿）时**不执行本闸**，先完成修订；进入「可定稿」状态才开闸（业主原话：「T5 之前若有修订但还不能定稿，则 G14 还是不执行」）。

> ⚠️ **原「复检收敛判据」（v2.12.32 的 4 条规则 + `g14_rerun: skipped_no_new_prose`）整体作废** —— 本修订起 G14 不再复检，「收敛/条件跳过/硬上限」等规则**已无适用对象**，故删除。

**降级与豁免**：轻量档（**2000-3000 字**）走内置自检（`selfcheck`），不 spawn 独立 checker；主人**显式要求关闭**（`exempted_by_owner`）→ 全项目不跑 + 必须在 `final/交付说明.md` 披露。
