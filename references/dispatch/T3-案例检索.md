10. **任何量级默认必 spawn**（教训 #267）：含 cases = 0 场景也走 0 条空卡协议，输出 `[C-空]` + 显式声明「本次无案例需求」；只有已记录的 `waived` 才可不执行检索。

11.1 **公开批评未成形诚实声明**：事件若「批评方截至检索截止未成形」，多方说法末加一句「截至 YYYY-MM-DD 检索截止，[Cxx] 案例公开批评尚未成形——学术检验仍待学界参与」
