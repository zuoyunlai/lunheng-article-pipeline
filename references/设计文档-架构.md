## 二、角色定义（9 角色，v2.4.0 更新）

| 编号 | 角色 | 职责 | 何时启动 |
|------|------|------|---------|
| **T0** | 主控 Coordinator | 定题、拆解、派发、终检、状态机 | 始终在线 |
| **T1** | 文献检索员 Literature Scout | 已发布学术文献/政策文件/统计年鉴检索 | Phase 1 |
| **T2** | 数据检索员 Data Scout | 已发布统计数据/行业报告/新闻数据检索 | Phase 1 |
| **T3** | 案例检索员 Case Scout | 具体事件/企业案例检索（**任何量级必 spawn**） | Phase 1 |
| **T4** | 分析员 Analyst | 论点拆解 + 论证结构设计 + 大纲编写 | Phase 2（T1+T2+T3 完成后） |
| **T5** | 写手 Writer | 正文撰写 + 修订执行 | Phase 3 |
| **T6** | 批判伙伴 Critical Companion | 从反方攻击论证（C1-C7） | Phase 3.6（T5 v2 后） |
| **T7** | 审计员 Auditor | 质量审计（G0-G14）+ 修订任务书 | Phase 4 |
| **T9** | 同行评审 Peer Reviewer（v2.4.0 新增） | 预演期刊审稿（6 维度评分 → accept/minor/major/reject） | Phase 4.5（**v2.4.6 按模式默认开启**：行业分析/学术默认开启，公众号可选；**v2.5.0 期刊匹配助手**学术模式默认输出 Top 3 推荐期刊） |

> **T8 终检** = 主控亲完成（无独立角色卡，v2.3.0 明确）
> **G14 中文 AI 痕迹闸（v2.4.0 新增）**：Phase 4.5 触发，与 T6 并行。8 类检测维度，LLM 推理判定（零 exec），0-2 类 Pass / 3-4 类 Warning 触发修订 / 5+ 类 Fail 强制修订。

详细定义：见 `agents/0X-*.md` 角色卡 + `glossary.md § 一 核心角色`

## 三、工作流程（5 阶段）

### Phase 0 定题（主控 × 人类）
- 4 选 1 同意关卡（全部同意 / 脱敏+本地 / 部分同意 / 全部拒绝）
- 主人确认主题/类型/篇幅/引用格式/deadline

### Phase 1 并行检索（T1∥T2∥T3 三方真并行，v2.3.0 改 T6→T3）
- T1 文献 + T2 数据 + T3 案例（含 0 条场景走空卡协议）

### Phase 2 分析（T4）
- 三角验证：[L] + [D] + [C]
- 反方论证规划 + 原创性声明

### Phase 2.5 大纲确认（人在环）
- 主人过目分析大纲

### Phase 3 写作（T5，v2.3.0 改 T4→T5）
- 初稿 v1 → 修订 v2/v3（≤2 轮）
- AI 去味 10 项 + 反方论证

### Phase 3.5 洞察补充（人在环，v2.1.3 新增）
- 主人补充深度洞察
- T6 批判伙伴产出 `analysis/批判报告-vN.md`

### Phase 4 审计（T7，v2.3.0 改 T5→T7）
- M 门（v2.2.0 + v2.2.1.2 + v2.2.4）+ G 清单（G0-G14）+ F 失败模式（F1-F9）
- 修订任务书（如打回）

### Phase 4.5 审稿 + AI 痕迹（v2.4.0 新增）
- **T9 同行评审**（可选，默认关闭）：模拟期刊审稿人 6 维度评分 → accept/minor/major/reject 建议
- **G14 中文 AI 痕迹闸**：8 类检测维度，LLM 推理判定（零 exec），0-2 类 Pass / 3-4 类 Warning 触发修订 / 5+ 类 Fail 强制修订
- **方法论实时可见面板**：status.md 加「方法论足迹」段（当前阶段/证据强度/已触发闸门/下一步预测/不确定性/模型健康度），主人实时看清进度

### Phase 5 终检（T8 主控亲完成，无独立角色卡，v2.3.0 重构明确）
- 证据包完整性 + 引用一致性 + AI 使用披露
- `final/定稿.md` + `证据包/` + `交付说明.md`

**M 门渐进式执行（v2.2.15）**：
- Phase 1.5（T1/T2/T3 完成后）：M-Integrity-1 + M-Form-6
- Phase 2.5（T4 分析后）：M-Form-3
- Phase 3.5（T5 v1 后，主人洞察）：M-Form-1/2/4/5
- Phase 3.6（T6 批判后）：M-Form-7 论证强度
- Phase 4.5（T7 审计后）：M-Exist-1/2/3 + M-Integrity-2
- Phase 5（T8 终检）：全部 11 项兜底复跑

（v2.2.15 渐进式执行模式：M 门分 5 阶段 + T8 兜底，P0 错误提前暴露，详见 `_shared/M-Gate-Algorithm.md` M-Form / M-Exist / M-Integrity 各阶段描述）
