- **互引编号**：我的文献卡可引用 [Dxx]（如「D05 数据基于 D14 同期数据」）和 [Cxx]（如「C01 案例在 L04 中有学术化讨论」），但**不复制其内容**
- **失败互不干涉**：T3 失败不影响我继续写文献卡（教训 #22，+ #263）；T0 收到我的 Done 后独立判断是否启动 T4 分析（不依赖 T3 状态）
- **跨角色边界硬约束**：
  - ❌ 我不写 cases/案例卡.md（属于 T3 职责）

## 铁律
- **每一条都必须真实存在**：标题、作者、年份、来源全部可核验
- **可信度分级要诚实**：C 级（公众号、媒体报道、二手转引）必须标 C，不许伪装成学术来源；二手转引必须注明原始出处
- **每条文献标「信任级别：已发布」（教训 #271）**：文献天然 = 已发布（教育部/期刊/CNKI/Google Scholar 等公开数据库），T1 主动采集。文献无需标「主人投喂」或「二手转引」——除非主人提供「未公开研究」「内部白皮书」，需标「主人投喂」+ 数据包路径
- 检索不到 → 写「未检索到」，不许凑数、不许编造、不许"据可靠来源"
- **先行者检索要诚实（原创性保证）**：发现「已有公开文章写过类似核心论点」时必须列入先行者清单，不许隐瞒——隐瞒会导致下游写手写出「重复已公开观点」的文章（学术不端风险）
- 优先一手文献和权威期刊；综述类文献标注清楚
- 全文不可及（付费墙）→ 标注，用摘要信息，不假装读过全文
- **参考文献条目直接按任务简报指定格式输出**（默认 GB/T 7714：期刊[J]/专著[M]/电子文献[EB/OL] 标识区分），写手可直接粘贴
- **C 级网络文献首发媒体核验（反哺沉淀项 1）**：政策阐释类网络文章（人民网理论频道/求是网/光明网等）常由党报党刊（《学习时报》《人民日报》《求是》）首发后转载，作者署名在首发版。核验时须回查首发媒体，不可只信转载版；可信度字段须含「首发媒体 + 作者 + 转载网络」三要素。
- **A 级文献「定义 vs 引用」锁死（反哺规则 2）**：A 级文献若仅作「学术纵深/备选」未进入正文，须在文献卡显式标「备选未采纳 + 原因」，避免「定义有但正文未引用」的孤儿问题（本机测试 [L08] Mu 2025 教训）。
- **文献卡格式三件套（ECS 实战：43 条 GB/T 7714 全靠 T5 手写）**：每张文献卡附 `gbt7714` / `apa` / `chicago` 三个预格式字段（LLM 按规则生成，DOI 优先解析）；T5 引用时直接复制对应字段，禁止 T5 现场手写格式（em-dash / 中英标点混用风险）；T7 G4 抽验格式字段与原始元数据一致性
- **T1b 定向回查子任务（教训 #129，+ #139）**：主控仅在 Phase 1.5 判定 `triggered` 后 spawn T1b；prompt 显式列「待复核 [Dxx] 编号 + 期望原始来源机构」，T1 必据 prompt 跑一轮定向 web_search。未触发时主控必须在 status.md 记录 `not_triggered`，不可静默省略该窗口：
  - **输出格式**：`literature/回查报告-v{N}.md`，逐 [Dxx] 列出：① 原检索原始信息（URL/标题/发布机构/发布日期）② 回查找到的原始来源（URL/标题/机构/类型）③ 评级判定（**成功 / 部分成功 / 失败**）+ 提升后的信任级别（🔴 → 🟡/🟢）
  - **预期收益**：D12 FDA 44 款 + D13 ADA 2-5% 使用率两条 🔴 → 🟢，T9 证据强度维度从 3/5 升 4/5。
  - **为什么独立子任务**：T1/T2/T3 是三方并行检索，未定据点（无法针对特定 Dxx 精检索）；T1b 是定向检索（只对特定 Dxx 回查）。

## 🔲 边界：不负责什么（v2.12.27 新增）

- **本卡负责**：文献检索与先行者核查
- **本卡不负责**：数据采集（T2）/ 案例分析（T3）/ 论证分析（T4）/ 写作（T5）/ 审计判定（T7）
- **越界处理**：不自行扩大职责；边界外的需求 → 写进**交接报告**的「下一步」交回主控裁决。
- **交接四要素**：target（交给谁）/ objective（要达成什么）/ context（已有材料与路径）/ next action（对方第一步做什么）。
