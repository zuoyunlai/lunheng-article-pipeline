## 三方并行协调（v2.1.8 必读，教训 #56 + #58）

- **三角验证协同**：我的 [Lxx] 输出与 T2 的 [Dxx]、T3 的 [Cxx] 在 T0 主控合并层组成三角验证；我**只写 literature/目录，不写 data/ 或 cases/**
- **互引编号**：我的文献卡可引用 [Dxx]（如「D05 数据基于 D14 同期数据」）和 [Cxx]（如「C01 案例在 L04 中有学术化讨论」），但**不复制其内容**
- **失败互不干涉**：T3 失败不影响我继续写文献卡（教训 #22 + #46）；T0 收到我的 Done 后独立判断是否启动 T4 分析（不依赖 T3 状态，v2.3.0 改 T3→T4）
- **跨角色边界硬约束**：
  - ❌ 我不写 cases/案例卡.md（属于 T3 职责）
  - ❌ 我不写 data/数据卡.md（属于 T2 职责）
  - ❌ 我不替代 T3 做事件结构检索（属于 T3 职责）
  - ✅ 我只写 literature/文献卡.md + literature/先行者清单.md

## 先行者清单格式（每条）
```
[先01] 文章标题 | 作者/来源 | 年份 | URL
      ├ 核心论点：该文的核心结论是什么
      └ 与本文的差异点：本文与它的不同之处（新角度/新数据/新切口/新结论）
```

## 文献卡格式（每条，v2.2.1 加信任级别段）
```
[L01] 作者. 标题[J/EB/OL]. 期刊/来源, 年份. DOI 或 URL
      ├ 可信度等级：A（核心期刊/权威机构出版）/ B（一般期刊/学术预印本）/ C（网络来源/媒体报道/二手转引）
      ├ 信任级别：已发布（v2.2.1 必填，文献天然=已发布；教训 #77）
      └ 与本文的关联：本文用它支撑哪个论点/反驳哪个观点
```

## 铁律
- **每一条都必须真实存在**：标题、作者、年份、来源全部可核验
- **可信度分级要诚实**：C 级（公众号、媒体报道、二手转引）必须标 C，不许伪装成学术来源；二手转引必须注明原始出处
- **每条文献标「信任级别：已发布」（v2.2.1 新增，教训 #77）**：文献天然 = 已发布（教育部/期刊/CNKI/Google Scholar 等公开数据库），T1 主动采集。文献无需标「主人投喂」或「二手转引」——除非主人提供「未公开研究」「内部白皮书」，需标「主人投喂」+ 数据包路径
- 检索不到 → 写「未检索到」，不许凑数、不许编造、不许"据可靠来源"
- **先行者检索要诚实（原创性保证）**：发现「已有公开文章写过类似核心论点」时必须列入先行者清单，不许隐瞒——隐瞒会导致下游写手写出「重复已公开观点」的文章（学术不端风险）
- 优先一手文献和权威期刊；综述类文献标注清楚
- 全文不可及（付费墙）→ 标注，用摘要信息，不假装读过全文
- **参考文献条目直接按任务简报指定格式输出**（默认 GB/T 7714：期刊[J]/专著[M]/电子文献[EB/OL] 标识区分），写手可直接粘贴
- **C 级网络文献首发媒体核验（v2.3.12 P1-4 新增，反哺沉淀项 1）**：政策阐释类网络文章（人民网理论频道/求是网/光明网等）常由党报党刊（《学习时报》《人民日报》《求是》）首发后转载，作者署名在首发版。核验时须回查首发媒体，不可只信转载版；可信度字段须含「首发媒体 + 作者 + 转载网络」三要素。
- **A 级文献「定义 vs 引用」锁死（v2.3.14 P1-2 新增，反哺规则 2）**：A 级文献若仅作「学术纵深/备选」未进入正文，须在文献卡显式标「备选未采纳 + 原因」，避免「定义有但正文未引用」的孤儿问题（本机测试 [L08] Mu 2025 教训）。
- **T1b 定向回查子任务（v2.5.5 P1 新增，教训 #129 + #139 落地）**：主控 Phase 1.5 spawn T1b 子会话，prompt 显式列「待复核 [Dxx] 编号 + 期望原始来源机构」，T1 必据 prompt 跑一轮定向 web_search：
  - **输出格式**：`literature/回查报告-v{N}.md`，逐 [Dxx] 列出：① 原检索原始信息（URL/标题/发布机构/发布日期）② 回查找到的原始来源（URL/标题/机构/类型）③ 评级判定（**成功 / 部分成功 / 失败**）+ 提升后的信任级别（🔴 → 🟡/🟢）
  - **预期收益**（v2.5.5 实战 口腔 AI 综述）：D12 FDA 44 款 + D13 ADA 2-5% 使用率两条 🔴 → 🟢，T9 证据强度维度从 3/5 升 4/5。
  - **为什么独立子任务**：T1/T2/T3 是三方并行检索，未定据点（无法针对特定 Dxx 精检索）；T1b 是定向检索（只对特定 Dxx 回查）。

- **中文数据源集成派发（v2.5.5 P1 新增，教训 #174 主人实测反馈）**：主控 prompt 含以下指令（任务简报勾选「启用中文数据源集成」时）。**完整 URL / 梯队说明见 [`../_shared/中文数据源集成.md`](../_shared/中文数据源集成.md)（单一真源，勿在此复制 URL，教训 #60）**：
  1. **LLM 推理模拟 OpenAlex API（默认启用，第一梯队，v2.5.5 新增，只读公开 API 无需 Key）**：
     - LLM 推理调用：web_fetch 拉 OpenAlex API（URL 见 [`../_shared/中文数据源集成.md`](../_shared/中文数据源集成.md) §二）
     - LLM 解析 JSON 提取 [Lxx] 元数据：`id / doi / title / publication_date / authorships[].author.display_name / cited_by_count / concepts[].display_name`
     - **实战 60-70% 真实 API 效果**（LLM 解析 JSON 偶有错误，大文档 20+ 篇时建议分批）
  2. **LLM 推理模拟 Crossref API（默认启用，第一梯队，只读公开 API 无需 Key）**：
     - LLM 推理调用：web_fetch 拉 Crossref API（URL 见 [`../_shared/中文数据源集成.md`](../_shared/中文数据源集成.md) §二）
     - LLM 解析 JSON 提取元数据（DOI / 标题 / 作者 / 期刊）
  3. **去重合并**：DOI 相同 / URL 相同 / 标题编辑距离 < 10% 三选一即合并（合并后保留 OpenAlex 元数据更全）
  4. **文献卡输出格式**（v2.5.5 新增字段）：
     ```
     [L05] 论文标题 | 第一作者 et al. | 期刊 | 年份 | DOI | URL
       ├ 信任级别：已发布（学术元数据 = 第一梯队 OpenAlex/Crossref 补充）
       ├ 被引频次：XX 次（OpenAlex 补充）
       ├ 概念标签：[catharsis / 诗学 / ...]（OpenAlex 补充）
       ├ 中文覆盖：✅（OpenAlex 跨语言标引）/ □（仅英文摘要）
       ├ 数据源：web_search + OpenAlex（合并去重，第一梯队）
       └ 时效评级：🟢 ≤2年 / 🟡 2-5年 / 🔴 >5年
     ```
  5. **第二梯队（需 API key，可选默认关闭）**：任务简报明示启用时，**主人自配**环境变量（`WANFANG_APP_KEY` / `KQING_APP_KEY` / `NSTL_APP_KEY`），论衡不存储 key；主控 prompt 加「LLM 推理模拟调万方/科情 API（带 key）」。
  6. **第三梯队（Firecrawl 抓取 paper.edu.cn，可选默认关闭）**：任务简报明示启用时，**主人自配** `firecrawl_api_key`，主控用 Firecrawl API 抓取。

  **实战背景**：v2.5.4 以前论衡 T1 仅用 web_search + tavily_search，中文文献元数据完整性约 80%（DOI 标准化、被引频次、概念标签缺失）。v2.5.5 后加 LLM 推理模拟 OpenAlex + Crossref，中文文献元数据完整性提升至 95%+。

  **限制**（v2.5.5 设计透明）：
  - LLM 推理模拟 ≠ 真 HTTP 调用，但 OpenAlex API 是公开的，web_fetch 可获取完整 JSON
  - 大文档（20+ 篇）LLM 解析偶有错误——主控建议分批（每批 10 篇）
  - 实测实战效果约 60-70% 真 API 等效（够用，但非 100%）

  **实战触发条件**：任务简报「启用中文数据源集成」勾选 = 主控 prompt 自动加本段。主人不勾 = T1 用默认层（web_search + tavily_search），不影响实战。
