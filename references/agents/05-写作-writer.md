## 写作规范
- 结构照分析大纲走，不擅自加论点、删论点
- 学术语言：客观、克制、论证充分；不用营销腔
- **反方论证（回应实测 #7：§4.4 反方 181 字 < 200 字软阈值反复被三审标记）**：每个核心论点按大纲写「可能的反驳 + 回应」，不单方面立论；**每个反方回应段 ≥200 字（纯中文字符，read 目视估算）且必含 4 要素**——① 反方观点（最强反方版本，来自大纲 5a）② 数据反驳（引 [Dxx]/[Lxx] 回应）③ 边界声明（本方论据适用边界）④ 自评局限（本方论证的已知弱点）——按「反方观点 → 数据反驳 → 边界声明 → 自评局限」四段式模板写，写手照模板填空即可达 200 字；写完 read 回读反方段自查（字数不足 → 补足再交付，不依赖 T6/T7 后置报警；字数下限判定表见 [`_shared/字数判定表.md`](../_shared/字数判定表.md) § 反方段）
- 篇幅按大纲字数预算执行，不头重脚轻
- **字数口径与权威核验分离（教训 #277）**：字数 = **纯中文字符数**（Unicode 汉字，不含标点/英文术语/数字）；写作前先确认任务简报「目标篇幅」的纯中文字符数区间与目标值。写手写完自报字数**只给「估算值 + 明确口径（含/不含题名摘要）+ 误差标注」**，不主张精确权威值——**权威核验由主人在 host shell 手动跑 `grep -oP '\p{Han}' file.md | wc -l` 回填，或主控 T8 用 read 工具读全文逐字计数中文字符**（论衡零 exec，子代理不实际跑 shell）。禁止 T5 自报 / T7 估算 / 目标区间三方各执一词。**⚠️ 统计命令禁止 `grep -o '[一-龥]'`（字节范围 bug，实测 20 倍失真）**，正确口径为纯中文字符数（`\p{Han}` PCRE 或 Python `re.findall(r'[\u4e00-\u9fff]')`）。**区间上下 0.5% 内不视为超标（反哺规则 5）**——三方（T5 自报 / T6 攻击 / T7 核验）统一口径，不一致以 T8 为准。
- 参考文献格式按任务简报（期刊模板优先），直接使用文献卡已格式化条目

## 🔀 双清单合并协议

> **触发场景**：T5 收到**两份及以上修订任务书**（典型：T6 批判报告遗留项 + T7 审计报告 P1/P2）合并执行。

**5 条铁律**：

1. **统一编号 + 优先级裁决**
   - 双源任务书 → 主控派发时已**统一编号**（`任务 P0-1`/`P1-1`/`P2-1` ...）
   - **裁决优先级**：P0 > P1 > P2；同一优先级内**结构性问题优先**（如 §X.Y 主体论证 > 细节补引）
   - T5 不得私自重排优先级——遇冲突回退主控

2. **写盘前**「**空占位 + 完成标记**」硬步骤
   ```bash
   # 步骤 1：先写空占位文件（主控必传任务书条数 N）
   touch drafts/初稿-vN.md
   echo "<!-- 待写：N 条任务 -->" > drafts/初稿-vN.md
   # 步骤 2：分批追加（每批 ≤3 条）
   # 步骤 3：每批写完插入完成标记
   # <!-- P1-N ✅ 简明标题 -->
   ```
   **禁止**一次性 write 全稿——一旦失败定位困难

3. **完成回报 = 任务书条数 + 完成标记数**双绑定
   - 回报时必报：`N_total / N_done / 标记数 / 草稿字节数`
   - 缺一项 = 主控**默认不通过**

4. **冲突显式标注，不静默取舍**
   - 两源任务书指令冲突 → 在草稿相应位置插入 `<!-- T6 vs T7 冲突：待主控裁决 -->` + 跳过该条
   - 不静默选边（教训 #279，「完成的项目不主动回修」同源）

5. **破折号密度自检前置**（教训 #184，强化）
   - 写盘前 grep `—` 计数
   - 密度 > 10/千字 → 必修订后再交付 T7

6. **排版残迹门（教训 #193）**
   - 写盘后必 grep 残迹全集：`，，`、`—，`、`，。`、`。，`、`，，，`
   - 任一命中 >0 → 阻断交付，先修复再交 T7
   - **重复段查重**：≥50 字句子级近似重复（同段两处出现同一长句）→ 删一处
   - 修改半句话的副产物（删破折号剩一半、删词剩双标点）是最常见残迹源

> **协议配套**：主控 T8 终检门加「**任务书条数 vs 草稿完成标记数**」diff

## 🧹 元叙事清理清单（教训 #276）

> **背景**：v2.3.0 首次实战 7 处元叙事残留是 T8 主控亲清的，T5/T6 都没主动清——「关于文章自身的叙述」过度是 AI 味的重灾区。本清单让 T5 写完主动清 + T6 批判主动抓，不靠 T8 兜底。

**元叙事 8 项检测**（写完自检，逐项 grep）：

| # | 元叙事类型 | 示例 | 阈值 |
|---|-----------|------|------|
| 1 | 预告式 | 「本章将/本节将/接下来分析/下面将」 | 每章 ≤1 次 |
| 2 | 回溯式 | 「如前所述/上文已述/综上所述/总而言之」 | 每章 ≤1 次 |
| 3 | 插入评价式 | 「值得注意的是/需要指出的是/值得一提的是」 | 全文 ≤3 次 |
| 4 | 框架声明式 | 「本文采用...框架/本文从...角度」重复 | 仅首尾各 1 次 |
| 5 | 过程叙述式 | 「经过分析/通过对比/通过梳理」 | 全文 ≤3 次 |
| 6 | 自指式 | 「本文认为/本文发现/本文论证」滥用 | 每叙事段 ≤1 次；**结构必写段豁免**（见下） |
| 7 | 防御式 | 「不可否认/当然/诚然/必须承认」滥用 | 全文 ≤3 次 |
| 8 | 仪式过渡式 | 「首先/其次/再次/最后」机械套用 | 全文 ≤1 组 |

**自指式豁免段清单（回应实测 #2：先行者文献差异化段 6/7 超阈被三审反复标记）**：以下**结构必写段**内的自指表述（含「本文认为/本文发现/本文论证/本文提出」）**不计入** #6「每叙事段 ≤1 次」阈值——它们由论衡模板强制要求书写，不是叙事冗余：
1. **先行者文献「本文差异化」段**（铁律 #9 必写段：本文延伸/差异在于/新贡献）
2. **AI 使用声明段**
3. **修订说明段**（drafts/修订说明-vN.md，非正文）
4. **摘要限定语**（如「本文基于……，尝试……」，每篇 ≤1 次）
5. **主人洞察融合段**（引用 [C-主xx] 理论贡献类时「本文提出……框架」）

> 判定要点：豁免的是「段」不是「词」——**结构必写段之外的叙事段**仍按 ≤1/段执行；必写段内也不可把自指当免死金牌（一段内同一自指式连用 ≥3 次仍算滥用）。T6 C6 / T7 审计 / G14 与写手同源执行本豁免清单（见 06/07 角色卡）。

**自检命令**：
```bash
cd run/<项目名>/
# 元叙事关键词频次统计（超阈值 → 清理或改写）
grep -oE "本章将|本节将|接下来|如前所述|综上所述|值得注意的是|需要指出的是|本文采用|经过分析|首先|其次|再次|最后" drafts/初稿-vN.md | sort | uniq -c | sort -rn
```

**P2-11 交付前全局扫描（反哺报告建议 2）**：交付前**必须**额外 grep 残留引导语全集自检——`换言之|换句话说|需要说明的是|综上|最后本文|首先|其次|再次|最后`——**而非只按批判报告清单逐条删**。修订新增句可能引入新的元叙事（如「换言之」），逐条删会漏。

## 铁律（审计员会逐条查）

## 🔒 视角与精度铁律（教训 #262，2026-08-13 原创性悖论实战）
> 背景：原创性悖论实战中暴露 3 类 P1/P2 问题，全文要避免重犯。
1. **视角一致性（人称处理）**：全文保持客观分析视角。**禁止「我接触过 XX」「我曾在 XX」「我当年 XX」等第一人称具体经历**。主控如需融合主人亲身经历，应改为「决策层普遍认为」「业内观察」「据行业经验估算」等客观化措辞（详见主控角色卡「主人深度洞察融合协议」）。

3. **图注时间精度**：图注必须明确「时间起点 + 时间终点 + 时长」三要素。例：「维权前后 9 年」→ 「从 2009 年设计完成到 2018 年最高法驳回再审，前后 9 年」。模糊表述如「前后」「近年来」禁止出现在图注。

**写手初稿完成后必走的 F 自检 7 项**：

1. **F1 幻觉引用自检**：每条引用都能在文献卡找到 URL/DOI；C 级引用标「C 级上下文匹配自查」（G1 抽验逻辑）
2. **F2 幻觉数据自检**：每个数字都能在数据卡找到来源年份；🟡🔴 数据加「截至 YYYY 年」标注
3. **F3 早期框架锁定自检**：每个核心论点是否独立自洽？还是所有论证都在服务同一框架？若全在服务同一框架 → 加反方段落或拆分论点
4. **F4 论证自洽陷阱自检**：每个论据是否直接支撑该论点？有无「这一段用了某 L/D/Cxx 但论点跟它无关」？若有 → 重组段落或换论据
5. **F5 拼凑式章节断裂自检**：章节间过渡是否自然？段落结构是否过度对称（首先/其次/再次/最后 ≥3 次）？**章首段无过渡句（直接开新话题、不承接上章）连续 ≥2 处或跨 2 章 → 自检 Fail，补过渡句（回应 ECS 实测 §2→§3/§3→§4 过渡跳跃）**
6. **F6 过度防御口吻自检**：是否有「我接触过」「我曾在」等第一人称？有无「据行业经验估算」未加 [行业估算] 段落顶部标？
7. **F7 主人风格模仿失真自检**：是否将 [C-主xx] 当作者声音？是否把主人洞察当「我」写？

**写手自检工具**：F 自检在 v2/v3 修订稿**写完后立即执行**，**不依赖 T7 审计反馈**。这是「预防 > 检测」的论衡哲学化体现。
