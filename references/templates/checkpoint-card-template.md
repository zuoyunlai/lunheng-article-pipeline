# 人在环节点呈现卡模板（v2.7.0，v2.7.2 挂版本同步链）

> **用途**：主控到达 Phase 0 / 2.5 / 3.5 / 5 时，按本模板骨架向主人呈现材料 + 选项。
> **原则**：结构固定、内容自由——主人一眼知道"到了哪步、要我拍什么"，但不受字数/格式束缚。
> **不强制**：模板是骨架不是表格；阶段特性不同，段落数可增不可减。

---

## 通用骨架（四节点共用）

```
🔵 Checkpoint [Phase X] — <阶段名一句话>

📋 已完成
<上一阶段做了什么，1-3 句话，含关键产物路径>

📂 待审材料
- <文件路径>（<一句话说明这是什么>）

❓ 需要主人决策
<一句话说清决策点>

选项：
- A. <选项A>
- B. <选项B>
- C. <选项C>（按需追加 D）

💬 备注（如有）
<模型降级 / 数据缺口 / 需要主人特别注意的事项，没有则省略整段>
```

> 主人回复后，主控将决策写入 `status.md`「人在环决策记录」段。

## 四节点选项清单（固定，不可自由发挥）

### Phase 0 · 定题
- **已完成**：主控读记忆 + 任务简报草稿已写
- **待审材料**：`01-任务简报.md`
- **选项**：
  - A. 开始（同意主题/篇幅/受众/外发范围，进入 Phase 1）
  - B. 补充信息（主人追加要求后重出简报）
  - C. 暂停（想再想想，不启动）
  - D. 拒绝（不写了）
- **必呈现**：外发数据范围四选一（全部同意 / 脱敏+SVG+本地 / 部分同意 / 全部拒绝）、可选服务三项（封面 / 记忆读取 / 多格式导出）

### Phase 2.5 · 大纲确认
- **已完成**：T1/T2/T3 检索 + T4 分析大纲
- **待审材料**：`analysis/分析大纲.md`（+ `literature/` `data/` `case/` 目录可选附览）
- **选项**：
  - A. 确认大纲（进入 T5 写作）
  - B. 修改大纲（主人指出方向，T4 重出）
- **必呈现**：建议图表位（数量/类型/数据源），三角验证状态（[L]+[D]+[C] 是否齐），**Phase 3.5 预授权（v2.7.3）**：A. 确认大纲且 Phase 3.5 到点仍呈现（默认）/ B. 确认大纲且 Phase 3.5 自动记「无补充」不再打扰（主人风格 continue-once-OK 时选，v2.3.3 教训 #138 + ECS 实战）

### Phase 3.5 · 洞察补充
- **已完成**：T5 初稿 v1
- **待审材料**：`drafts/初稿-v1.md`
- **选项**：
  - A. 补充洞察（主人写出要加的内容/方向，T5 融入 v2）
  - B. 无补充（直接进 T6 批判）
- **必呈现**：初稿字数 vs 目标、AI 痕迹初检结果（如有）

### Phase 5 · 终稿验收
- **已完成**：T8 终检 + 交付说明
- **待审材料**：`final/定稿.md` + `final/交付说明.md`
- **选项**：
  - A. 接受（项目完成，T8.5 GRANTED）
  - B. 补改（指出要改的点，T5/T8 修订）
  - C. 重走某阶段（指定从哪个 Phase 重来）
  - D. 延期（暂不决定，项目挂起）
- **必呈现**：终稿字数、AI 痕迹终检结果、多格式导出 6 选项（md/latex/docx/pdf/全产/跳过）、方法论附录勾选（附/不附，v2.7.3）

## 设计约束（为什么这样定）

1. **选项固定**：四节点的选项枚举是从 phase-order.yaml + status.md decision 字段映射来的，主控不能自创选项——主人看到的就是全部合法路径。
2. **内容自由**：「已完成」「待审材料」「备注」三段内容主控自由填写，不卡字数不卡格式。
3. **备注可省**：没问题时不写「备注」段，不搞"无备注"占位。
4. **Phase 0 例外**：外发数据同意 + 可选服务呈现是合规硬约束，不是"备注"，必须出现在选项段内。
5. **不替代对话**：主人回复可以自由表达（"改一下第三节的论点"），模板只规范呈现，不约束回复。
