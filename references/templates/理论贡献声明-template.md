# §2.3 理论贡献声明模板（v2.14.0 起必填）

> **版本**：v2.14.0-block-B（W3 落地）
> **适用场景**：分析员（**T4**）在 `analysis/分析大纲.md` §2.3 产出三层声明 + L1-L4 主张
> **字数**：≥200 字（标准档）/ ≥80 字（轻量档简版）
> **真源对照**：[理论贡献-protocol.md](../_shared/真源/理论贡献-protocol.md)

## 模板结构

```markdown
### §2.3 理论贡献声明

#### 三层声明（必填）

| 层 | 是/否/n/a | 一句话说明 |
|---|-----------|----------|
| 概念层 | 是 / 否 / n/a | [如：「本文提出 XX 新概念，区分 A/B 两类案例」] |
| 机制层 | 是 / 否 / n/a | [如：「本文揭示 XX 通过 YY 路径影响 ZZ 的机制」] |
| 预测层 | 是 / 否 / n/a | [如：「本文预测如果 X 发生则 Y 失败」或 n/a + 解释] |

#### L1-L4 层级主张（最多 2 项）

- **主张 1**：L2 拓展（已知方法+新应用 / 新方法+已知概念）
  - 论据：本文将 [方法 X] 首次应用于 [场景 Y]，对照 [先行者文献 Z] 的差异在于 [...]
- **主张 2**（可空）：L3 创新（新方法+新概念 / 新预测）
  - 论据：[...]

#### 修订承诺

- 修订轮（v2+）新增引用必标注 [Lxx] + 先行者文献 + 「本文差异化」段（避免与先行者重合风险）
- 预测层 n/a 时，正文 §6 结论处显式声明「本文为 XX 研究，无新预测」（诚实优先）

#### 联动

- T6 批判 C1 L1-L4 必填：与作者主张对比，判定 agree / partial_agree / disagree
- T9 D1 评分 10 分制（概念 3 + 机制 4 + 预测 3）：独立评分
- G18 真源 §12：前置理论框架与本文创新点对照
```

## 三层声明判定示例

### 示例 1：实证研究

| 层 | 是/否/n/a | 一句话 |
|---|-----------|--------|
| 概念层 | 否 | 本文沿用「原创性保护强度」既有概念 |
| 机制层 | 是 | 本文揭示「分段法律修订 + 行业自治协同」双轨机制 |
| 预测层 | 是 | 本文预测「2021 后判决支持率显著上升」 |

**L 主张**：L2 拓展（已知方法 [OLS] + 新应用场景 [中国家居品牌]）

### 示例 2：应用研究

| 层 | 是/否/n/a | 一句话 |
|---|-----------|--------|
| 概念层 | 是 | 本文提出「轻量档适配」概念 |
| 机制层 | 否 | 本文未揭示新机制 |
| 预测层 | n/a | 本文为应用研究，无新预测 |

**L 主张**：L1 应用（已知方法+轻度门槛）

### 示例 3：思辨研究

| 层 | 是/否/n/a | 一句话 |
|---|-----------|--------|
| 概念层 | 是 | 本文提出「中介美学」概念（区别于 catharsis 通俗义） |
| 机制层 | 是 | 本文揭示「丑学情感陶冶」机制 |
| 预测层 | n/a | 本文为思辨研究，无可证伪新预测 |

**L 主张**：L3 创新（新概念+新机制）
