## ⚠️ 样本量与统计强度自检（v2.5.18 P1 新增，主控 Phase 0 必填）

> **背景**：实战复盘（v2.5.13 实战）发现 n=5 个项目撑「80% 成功率」全称命题，置信区间过宽（28%-99%）。论衡不强制要求大样本，但**主人需自己意识到样本量限制**。

### 问题 1：本文核心论点是否需基于具体样本数据？
- □ 否（**理论/哲学/方法论类**，不限样本量）：主控跳过样本量自检
- □ 是（**实证/案例研究/统计推断类**，必需样本量评估）：
  - 预估样本量 N = `<N>` 条记录 / `<N>` 个案例 / `<N>` 篇文献
  - **样本量限制诚实声明**（必填，避免「小样本撑强论断」）：
    - □ n<10：添加限定词「**探索性 / 初步发现 / 待扩充验证**」，T9 评审自动打 ≤3 分
    - □ n=10-30：默认「**初步证据**，可发期刊 = 行业评论 / 案例研究，不适严苛量化研究**
    - □ n=30-100：默认「**中期样本量**，可发中等期刊」
    - □ n>100：默认「**充足样本量**，可发主流期刊**

### 问题 2：若论文是案例研究，需要几个案例才足够支撑结论？
- 主人拍板最低样本量 N = `<N>` （默认 3，**对照专家建议 + T4 预检**）
- 若 T4 实际检索结果 < 主人拍板阈值 → 触发 Phase 2.5 主人二次拍板（接受小样本 / 扩检索 / 缩论点）

### 警告原则
- **n<10 撑强论断是论衡红线**——T6 批判 C2 会抓、T9 评审会打 ≤3 分、T7 审计 G11 会标「样本不足」

## 主人深度洞察素材（2026-08-13 起，v2.1.4 明示化，v2.1.5 加类型分类）

**两种类型的区别**（论衡 v2.1.5 明示化）：

| 类型 | 定义 | 写手引用策略 | 示例 |
|------|------|-------------|------|
| **观点来源** | 主人亲身观察 / 业内判断 / 从业经验 | 作为「业内观察」引用，写明「据主人从业观察/业内经验」，不当作实证数据用 | 「主人『我接触过的教师很市例精明』」 |
| **理论贡献** | 主人的原创框架 / 结构性判断 / 新提法 | 作为「本文提出的框架」引用，**不是论据是论点**，写手需发展论据支撑 | 主人「五方合谋」框架 → 写手需展开五方各自实证支撑 |

**注意**：① [C-主xx] 不进入 cases/案例卡.md（独立编号空间）；② 终稿文末「案例来源」节需为每个 [C-主xx] 留 1 条「主人深度洞察」说明（含任务简报第 X 行出处 + 类型）；③ 主控融合时需按写手卡「主体声音 ≠ 第一人称经历」铁律客观化处理（详见设计文档 原创性保证 + 写手卡视角与精度铁律）；④ **类型必须在 Phase 3.5 由主人明确标注**——主控不可默认推断，因为「理论贡献」+「观点来源」的边界很微妙，主人最清楚。

**洞察-数据一致性预检（v2.3.2 新增，教训 #132）**：主人洞察里若引用了具体数据（如「中国 61% 监管信任」），主控在 Phase 1 检索后必须**回查该数据是否可被检索到**——若不可检索/不可验证 → 标 🔴，T4 分析员准备替换为可检索数据（或让主人补充数据出处）。**防止主人洞察里的「引文锚」是不可验证数据 → 写手误当硬数据引用 → T6 攻击「数据无源」**。

## v2.1.0 心跳要求（写到任务简报后由主控+角色同步执行）
