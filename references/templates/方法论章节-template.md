> **版本**：v2.14.0-block-A（W1 落地）

> **真源对照**：[方法论-审计清单.md](../_shared/真源/方法论-审计清单.md) G18 12 项

## 模板结构（6 子节）

```markdown
## §4 研究方法

### 4.1 研究设计

- **设计类型**：实证研究 / 思辨研究 / 应用研究 / 历史研究 / 文献综述（**单选 + 一句理由**）
- **适用边界**：本文研究问题类型（是什么、不是什么）

### 4.2 数据

- **数据来源**：一手 / 二手 / 公开数据库 / 主人投喂（**单选 + 简述**）
- **抽样方法**（仅实证）：随机 / 分层 / 目的性 / 全样本 + 简述
- **样本量与时间跨度**：N=?，时间 = YYYY-MM ~ YYYY-MM
- **样本流失率**（如适用）：N_initial / N_final / 流失率

### 4.3 变量

- **核心自变量**：定义 + 测量方式 + 来源 [Lxx]/[Dxx]
- **核心因变量**：定义 + 测量方式 + 来源 [Lxx]/[Dxx]
- **控制变量清单**：≥3 项 + 来源 [Lxx]/[Dxx]

### 4.4 模型与分析方法

- **主模型**：公式 / 结构方程 / 定性方法
- **替代模型**（仅实证）：≥1 个换主模型
- **识别策略**（仅实证因果推断）：实验 / IV / DiD / RDD / PSM + 假设陈述
- **分析工具**：定量 / 定性 / 混合 + 主要软件/方法

### 4.5 内生性处理（如适用）

- **内生性来源**：遗漏变量 / 反向因果 / 测量误差 / 选择性偏差
- **处理策略**：工具变量 / 固定效应 / 倾向得分匹配 / 安慰剂 / 其他
- **处理效果评估**：本文如何应对

### 4.6 局限性

- **最大局限**：≤3 条 + 简述
- **对结论的影响**：每条局限如何影响主要结论
- **未来研究方向**：具体下一步动作（不写模糊建议）
```
