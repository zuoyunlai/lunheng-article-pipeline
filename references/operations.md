## 配图生成规范（Phase 4.4）

> **术语澄清**：「零 exec」= 不执行 shell 命令（`exec` 工具禁用），是**执行能力边界**；「零外发」= 不向外部发送数据，是**数据传输边界**。两者**不是一回事**：数据图表 SVG 两者都满足（本地 write，零外发零 exec）；检索类工具（`web_search` / `tavily_search` 等）**会外发检索关键词与目标 URL**——勿将「零 exec」误解为「不向外部发送任何数据」。**封面与格式转换已不在流水线内**（见下条）。

- **数据图表**：主控用 `write` 工具手写 SVG 矢量图（参考 [`templates/图表-SVG-template.md`](templates/图表-SVG-template.md)），**禁止文生图**（数字不可控）。图位来自写手标注的 [图N]，图上数字必须来自数据卡，与正文 [Dxx]/案例卡 [Cxx] 一致，生成后抽查核对。SVG 是文本，主控 LLM 本地 `write` 生成——**零外发、零 exec**（不执行 shell、不调用外部服务，纯本地写文件）。
- **封面与格式转换（v2.12.52：不在流水线内）**：论衡 agent **不调用** `image_generate`，也**不执行**任何格式转换（`rsvg-convert` / `pandoc` / ImageMagick / 任何转换 binary）。封面视觉、docx/pdf/latex 导出、SVG→PNG 转换**不进 Phase 0 选项、不进任何 Phase 动作**；统一在 **T8 终检后**由主控写入「主人自行操作建议清单」（含命令模板 + 执行者 = 主人 host shell），由主人在 agent 流程之外自行执行。如主人不生成封面，`final/图件/` 仅含 SVG 数据图件即可。
- **中文字体**：SVG 文本元素用 `font-family` 指定 CJK 字体栈（如 Noto Sans CJK SC），避免目标渲染环境缺字体；不使用 matplotlib 等需 exec 的工具链（数据图表 = 主控 write 手写 SVG）
- **图件入 final/图件/**，交付说明列清单；数值标签与来源注释避免同侧重叠（来源统一放底部）
- **案例示意图**（可选）：复杂事件链可用 SVG 画时间线/关系图，不画文生图

## 写作禁做清单（AI 去味 10 项，审计员逐项查）

1. 排比堆砌（连续 3 组以上同构排比 → 拆掉）
2. 金句密度过高（每千字不超过 1 句"点睛句"）
3. 主体声音 ≠ 第一人称经历（要有「本文认为/本研究」的主体声音；**禁止**「我接触过 / 我曾在 / 我当年」等第一人称具体经历，见 [`agents/05-写作-writer.md`](agents/05-写作-writer.md)）
4. 缺具体细节（论证必须有具体案例/数字/场景支撑）
5. 过度防御性表述（"值得注意的是""不可否认"滥用）
6. 抽象概念密度过高（一段超 2 个抽象大词 → 拆解+举例）
7. 段落结构过度对称（避免每段"总-分-总"机械对称）
8. 学术过渡词过多（"综上所述""进而""由此可见"克制使用）
9. 表格过多（非必要不列表）
10. 缺研究者个人观察（正文要有自己的判断和发现）
