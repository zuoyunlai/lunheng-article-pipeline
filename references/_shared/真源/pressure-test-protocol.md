# T9b 压力测试协议（v2.14.0）

> **定位**：终稿形成后的独立压力测试；不是 T6「批判伙伴」的替代，也不是 T9 盲审评分。
> **执行者**：T0 主控亲完成，不 spawn。
> **输入白名单**：`final/定稿.md` + `audits/审稿报告-vN.md`；不得读取 T7 审计报告、内部证据卡或过程稿。
> **输出**：`audits/压力测试报告-vN.md`；默认不写入 `final/交付说明.md`。

## 一、三类压力剧本

### 1. 方法论审查者

检查研究设计的内部效度与替代解释：

- 内生性：遗漏变量、反向因果、选择性偏差
- 因果识别：识别策略与命题是否匹配，关键假设是否明示
- 测量误差：核心概念是否被恰当操作化
- 替代解释：是否存在同样能解释主要结果的竞争机制

输出：攻击点、终稿已有防御、仍然暴露的缺口、严重度。

### 2. 立场与范围审查者

检查论题预设、价值判断和结论边界：

- 选题是否预设单一结论
- 价值判断是否被伪装成事实判断
- 普遍性/必然性表述是否超出证据
- 不利证据或反方解释是否被遗漏

本剧本只审文本的论证公平性，不对作者或群体作政治归因。

### 3. 跨语境审查者

检查研究结论在不同语境中的可推广性：

- 研究情境依赖是否明确
- 概念转换或翻译是否改变含义
- 样本代表性是否支持外推
- 是否与相关国际/跨学科理论发生有效对接

## 二、严重度与出口

- 🔴 高：主要结论可能被击穿；主控建议回退 T5/T7，并暂停交付
- 🟠 中：论证可保留，但应补边界、替代解释或局限性
- 🟡 低：仅记录为后续优化，不阻断

T9b 不改变 T9 的盲审评分，不代替 T7 的形式/事实审计，也不自行触发修订；如需修订，主控在报告中提出建议并交主人拍板。

## 三、报告字段

1. `audited_artifact`：path / bytes / sha256（如可得）
2. 输入与独立性边界声明
3. 三类剧本逐项攻击清单
4. 严重度统计
5. 主控综合判断：通过 / 建议修订 / 暂停交付
6. 是否建议回退 T5 或 T7，以及理由
7. 未覆盖范围与已知限制
