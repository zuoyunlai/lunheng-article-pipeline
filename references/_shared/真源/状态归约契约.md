# 状态归约契约（字段级写入权 + 归约器）

> **性质**：唯一真源（新增）｜ 版本戳由「自动同步」脚本维护
> **一句话**：规定「谁能写哪个产物 / 并行写怎么合 / 冲突怎么判」。
> **术语借自 LangGraph 的 reducer（归约器）**；论衡零 exec，落地形态 = **书面契约 + 主控人肉执行**，不是运行时拦截。
> **冲突口径**：任何角色卡 / 派发话术 / 模板 / 其他真源与本文件不一致时，**以本文件为准**；改口径只改本文件一处。

## 1. 背景（为什么需要）

**判例（2026-09-25，E1-3 微型实测 D-1）**：T1 与 T3 并行 spawn 同写 `run/<项目名>/research/evidence-register.md`。T3 于 22:14 写入 11 条 `case_evidence`，T1 于 22:30 收尾**整文件写盘** ⇒ T3 段**全部消失**。危险点：文件**非空且格式合法**，状态机与 T7 审计**都无法从文件本身发现缺失**，属静默丢证据。

该判例此前只写在 `evidence-object-model.md` §2.4，**未普适化**。本契约把「分片写」从**单个文件的经验**上升为**全产物族规则**。

## 2. 五种归约口径

| 口径 | 语义 | 对应 LangGraph reducer |
|---|---|---|
| `overwrite` | 独占覆盖：唯一写者，后写覆盖前写 | 默认 reducer |
| `append` | 仅追加：写者只追加自己的行/段，从不整文件覆盖 | `operator.add` |
| `shard_merge` | 并行写者各写分片 → 主控在并表时刻合并 | 多路输入 + 归约 |
| `versioned_replace` | 带版本字段的覆盖：核对版本/指纹一致才覆盖 | 带 upsert 的 reducer |
| `keep_window` | 截断保留：只留最近 N 条 / 指定窗口 | `manage_list(keep)` 风格 |

## 3. 硬规则（全产物族适用）

- **R1 唯一整文件写者**：任一产物任一时刻只有唯一「整文件写者」；非唯一写者只能 `append` 或写自己的分片。
- **R2 分片优先**：一个路径若存在 ≥2 个并行写者 ⇒ **必须分片**（`<路径>-<角色号>.md`），禁止并行角色整文件覆盖主表。
- **R3 派发前置声明**：主控 spawn 任务书必须写明「本路径是否存在其他并行写者」。
- **R4 并表归属**：分片并表由**主控**执行；并表后**保留分片不删**（分片是溯源证据）。
- **R5 覆盖禁令**：禁止用 `write` 覆盖任何已被其他角色写过的文件。
- **R6 冲突显性**：发现两写者口径冲突 → **停并记 P1**，不得静默择一。

## 5. 并表纪律与抽验

- **并表时机**：T4 初始映射前、T7 抽验前各做一次。
- **抽验增项（T7/T8）——分片齐全性**：主表与**全部**分片均存在且非空；某并行角色分片缺失 ⇒ 记 **P1**。
- **归约一致性**：主表与分片记录数 / 口径不一致 ⇒ 记 **P1**。
- **空表不算完成**：空表、只写统计不写记录、统计与记录不一致，均不得判为已完成。

## 7. 边界（零 exec）

- 本契约是**书面纪律**，**不是运行时拦截**——论衡无代码层锁，靠主控执行 + T7/T8 抽验。
- 凡涉字节 / `sha256` / 指纹的判断，属**主人侧量值**；未回填时记 `pending_owner_verification`，**不得判通过**。
- 本契约**不新增**外发类别、`exec`、宿主配置读取或运行时数据库依赖。
