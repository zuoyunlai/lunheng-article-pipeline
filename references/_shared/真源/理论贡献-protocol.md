> **触发**：每个项目必跑（与 G18 / G14 同档条件决定）

## 一、设计哲学

本协议不是「给理论家看的炫技清单」，是论衡面向顶刊评审的「**理论贡献可证**」承诺：

- **三层声明 = 创新可被反方攻击的入口**：评审问「贡献在哪」，作者按层指认即可
- **L1-L4 层级 = 创新程度的诚实刻度**：避免「首创」「填补空白」等夸大修辞
- **诚实优先**：应用研究 / 思辨研究允许预测层声明 n/a，但**必须解释为什么 n/a**

### 预测层（prediction_layer）

> 是否给出可证伪新预测？

- **是 / 否 / n/a + 一句话**：
- **n/a 强制约束**：应用研究可声明 n/a，但**必须解释为什么 n/a**（如「本文为应用研究，无新预测」）
- **预测形态**：可证伪命题 + 反例条件 + 验证方法（如「如果 X 发生，则 Y 失败」）

## 三、L1-L4 层级判定（必填）

### L1 应用（routine_application）

- 已知方法 + 已知概念
- 例：「用 OLS 估计 X 对 Y 的影响」（无新方法/新概念）

### L2 拓展（extension）

- 已知方法 + 新应用 / 新方法 + 已知概念
- 例：「用 OLS 估计 XX 行业 X 对 Y 的影响」（新应用场景）
- 例：「用工具变量法估计 X 对 Y 的影响」（新方法+已知场景）

### L3 创新（innovation）

- 新方法 + 新概念 **或** 新预测
- 例：「用工具变量法估计 [新概念] 对 Y 的影响」（新方法+新概念）
- 例：「验证 [新预测] 是否成立」（新预测）

### L4 范式（paradigm_shift）

- 新框架替代旧框架
- 例：「用 [新框架] 替代 [旧框架] 解释 XX 现象，差异点 ZZ」（范式更替）

**L 主张限制**：单文最多主张 **2 项**（避免「通篇全是新」的浮夸）

## 七、修订建议

1. **应用研究**：可声明 L2 拓展 + 概念层 n/a + 预测层 n/a + 一句解释（避免硬填）
2. **思辨研究**：概念层 + 机制层必填；预测层可声明 n/a
3. **实证研究**：三层全必填 + L3 创新主张（否则算 L1-L2 拓展）
4. **博士论文**：三层必填 + L3-L4 主张至少 1 项（否则缺乏理论贡献）

## 八、实战陷阱

> **背景**：原创性悖论实战（2026-08-13）暴露 3 类 P1/P2 问题：
> 1. L1 应用冒充 L3 创新（无新方法/新概念但声称「首次提出」）
> 2. 预测层填空（应用研究硬填可证伪预测，但实际不成立）
> 3. 概念层与机制层混淆（声称揭示「机制 X」，实际只是相关性）

> **防御**：T6 批判 C1 L1-L4 必填（与作者主张对比，判定 agree / partial_agree / disagree）；T9 D1 评分独立报告。
