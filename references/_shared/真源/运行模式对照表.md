## 1. 三值定义（复用 status.md「运行性质」字段）

| 值 | 含义 | 四节点行为 | 交付效力 | 披露 |
|---|---|---|---|---|
| `生产·人在四环` | 生产 · 逐环拍板（现状默认体验） | 逐环呈现卡、等待拍板 | 正常 | 无需额外披露 |
| `生产·全自动` | 生产 · Phase 0 一次性预授权（**推荐呈现**） | 2.5/3.5/5 不呈现卡，按 §3 落值；Phase 0 本身仍交互 | **正常**（与人在四环等效） | **三处披露**（v2.12.43 纪律扩展） |
| `测试模式` | 测试（v2.12.38 语义不变） | 2.5/3.5/5 自动通过 | 不具备交付效力 | 三处披露（既有） |

- **Phase 0 在两生产模式下都必答**：运行模式、外发同意 4 选 1、可选服务、文件清单——
  **选全自动不隐含任何外发同意**（与同意门正交，`关键协议.md` 确定性规则第 4 条）。
- **不答 ≠ 全自动**：运行模式无应答 ⇒ `pending_owner_halt`（fail-closed 不变）。
- **「（推荐）」标注纪律**：只影响呈现顺序与文案，**不构成默认值**；两选项必须同屏并列、
  各自代价一并呈现（全自动 = 快、只看终稿，但四环未逐环人工审阅；人在四环 = 逐环把关，约 1-3 小时在场）。

## 2. 预授权机制（生产·全自动的唯一合法形态）

**核心判据：预授权 ≠ 自动继续。**

- 预授权 = **Phase 0 一次性决策**，记录于 `01-任务简报.md`「运行模式」字段（`run_mode: 生产·全自动`）；
- 各自动节点**仍写合法枚举 decision**（词表零新增）+ `owner_confirmed_at=<Phase 0 时间>` +
  `preauthorization_basis=任务简报「运行模式」`；
- `status.md` 留痕 `checkpoint_status=preauthorized`（该枚举值**仅本模式合法**）；
- 主控在对话流留一行**备案通知**（非提问、不制造新决策、不重发材料）；
- **fail-closed 尾巴**：预授权记录缺失 / 含糊 / 与实际节点不符 ⇒ 该节点**按人在四环呈现卡**，
  不得据「主人选了全自动」prose 推定（与同意门同构）。
- **silence_doctrine 分界**：`forbidden_kinds` 指「**无授权**情况下静默推进」；预授权是**有授权**的
  枚举落值，不属禁止枚举——但**把预授权扩大到非授权节点 / 非枚举值 / 记录缺失仍推进 = auto_continue**，阻断级。

## 5. 永不自动的人工停点（两模式一致，全自动也不豁免）

1. **异常三选**：`provider_silence_escalation`（同 provider 连续静默 ≥3）/ `audit_revision` 轮次耗尽 /
   T1b 定向回查耗尽 / G14 风格复检耗尽——halt 呈主人，无默认项。
2. **写入失败**：`write_failed` / readback failed / 锚点丢失（`关键协议.md` 重要写入完整性）——停人环。
3. **对账失败**：`acceptance_reconciliation` 四项任一不符——halt，不得自动接受。
4. **同意门**：外发同意缺失/不一致——fail-closed 阻断（与运行模式正交）。
5. **能力越权**：`capability_excess` 阻断级——停。
6. **质量门**：全部 G/M/G14/T7/T9/T8 照跑照判，全自动不触碰任何门判据。
7. **pipeline-doctor** `blocked`——停。
8. **非节点期间改方向**（换题/换结构）——暂停确认（`关键协议.md` 非节点输入处理表）。

> 设计理由：**全自动省的是「例行拍板」，不是「出事时的判断」。** 未来要把某一停点也自动化，
> 须逐项在本表登记并升版本，不得 prose 推定。

## 6. 运行期模式切换（非节点插话处理）

| 场景 | 处理 |
|---|---|
| 全自动 → 人在四环（「后面每环我都要看」） | 暂停 → 确认 → 改简报 `run_mode` + status 留痕；**未消费**预授权节点改回逐环呈现；**已消费**节点不追溯重开（重开走 `restart_phase`） |
| 人在四环 → 全自动（「后面全自动吧」） | 暂停 → 确认 → 补记预授权（basis = 本次插话原话 + 时间）→ 后续节点按 §3 |
| 测试模式 ↔ 生产模式互切 | **禁止中途互切**（三处披露 + T8 机械核对会被破坏）；须 Phase 0 重定 |
