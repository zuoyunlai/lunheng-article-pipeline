## Phase 3 写作（T5 写手）

### 执行顺序

```
主控 spawn T5 写手：
输入：
  - 01-任务简报.md（写作偏好/风格基线）
  - analysis/分析大纲.md（或 -revised.md）
  - literature/文献卡.md
  - data/数据卡.md
  - cases/案例卡.md
  - status.md（图表拍板结果）

输出：
  - drafts/初稿-v1.md
```

### T5 写作铁律（10 项必须遵守）

#### 1. 引用必标编号

```markdown
错误：
> 根据研究显示，XXX 现象普遍存在。

正确：
> 根据 Zhang et al. (2023) [L05] 研究显示，XXX 现象普遍存在。
```

**规则**：
- 文献引用：`[Lxx]`
- 数据引用：`[Dxx]`
- 案例引用：`[Cxx]`
- 不允许「根据研究」「有数据表明」等模糊表述

#### 2. 数字必标来源

```markdown
错误：
> 2023 年，中国 XXX 市场规模达到 500 亿元。

正确：
> 2023 年，中国 XXX 市场规模达到 500 亿元 [D12]。
```

**规则**：
- 所有数字（百分比/金额/数量）必须标 `[Dxx]`
- 估算数字也要标来源（如 `[D12] 基于 XX 方法估算`）

#### 3. 案例必标编号

```markdown
错误：
> 例如，某互联网公司通过 XXX 方式实现了突破。

正确：
> 例如，字节跳动 [C03] 通过 XXX 方式实现了突破。
```

**规则**：
- 具体案例必须标 `[Cxx]`
- 案例卡中必须有对应条目

#### 4. AI 去味 10 项

| 类型 | 错误示例 | 正确替代 |
|------|---------|---------|
| 1. 学术模板语 | 「值得注意的是」 | 直接陈述，删掉这句 |  <!-- G14 九类判定真源 = gates/14-中文AI痕迹-gate.md §二 + checkers/中文AI痕迹-checker.md（本节不重列九类） -->
| 2. 句式同质化 | 连续 3 句「XXX，XXX，XXX」 | 变化句式 |
| 3. 学术套话 | 「具有重要意义」 | 说清楚什么意义 |
| 4. 破折号滥用 | 「XXX——即 YYY」 | 改用冒号或分句 |
| 5. 三项排比 | 「从 A、B、C 三个角度」 | 必要时保留，非必要时简化 |
| 6. 人称错位 | 「笔者认为」（AI 没有笔） | 「本文认为」或「研究发现」 |
| 7. 个人辨识度缺失 | 全文客观陈述，无作者立场 | 适当表达观点 |
| 8. 党报话语堆砌 | 「在新时代背景下」 | 除非主题相关，否则删 |
| 9. 空洞形容词 | 「显著提升」 | 用数据：「提升 30%」 |
| 10. 过度转折 | 「然而」「但是」高频 | 减少转折词，直接陈述 |

**G14 中文 AI 痕迹闸**会检测这 9 类（真源 = `gates/14-中文AI痕迹-gate.md`），3 类以下 Pass，5 类以上 Fail。

#### 5. 章节字数预算遵守

```
预算：第一章 1200 字
实际：1180 字（98%）✅

预算：第二章 1500 字
实际：2100 字（140%）❌ 超标
```

**规则**：
- 允许 ±10% 弹性
- 超过 ±15% 必须在交接报告说明原因

#### 6. 图表占位标记

```markdown
## 第一章 第 2 节

XXX 趋势如图 1 所示。

[图1：XXX 趋势图]
（数据源：[D05][D12]）

从图中可以看出，...
```

**规则**：
- Phase 2.5 拍板的图表，T5 在对应位置标 `[图N：标题]`
- 标注数据源 `[Dxx]`
- Phase 4.4 主控会填充实际 SVG

#### 7. 反方论证融入

```markdown
错误：
> XXX 观点是正确的。（单边叙事）

正确：
> 有观点认为 YYY [L08]，但这种看法存在局限：第一，...；第二，...。
> 相比之下，XXX 观点更能解释 [D12][C03] 的现象。
```

**规则**：
- 核心论点章节必须包含反方论证
- 不是「打稻草人」，而是真实回应反方依据

#### 8. 时间锚点显式化

```markdown
错误：
> 近年来，XXX 现象日益明显。

正确：
> 2020-2023 年间，XXX 现象日益明显 [D12]。
```

**规则**：
- 不用「近年来」「目前」等模糊时间
- 显式标注年份或时间区间

#### 9. 三角验证体现

```markdown
错误：
> XXX 论点成立。（证据单薄）

正确：
> XXX 论点得到多重证据支撑：
> - 文献层面，Zhang et al. (2023) [L05] 发现...
> - 数据层面，2023 年统计显示 [D12]...
> - 案例层面，字节跳动 [C03] 的实践证明...
```

**规则**：
- 核心论点章节必须体现三角验证（或说明为何只有两项）

#### 10. 原创性差异点体现

```markdown
## 引言

已有研究（Li, 2022 [L01]; Wang, 2023 [L03]）从 XXX 角度分析了该问题。
本文则从 YYY 角度切入，使用 2024 年最新数据 [D05][D12]，发现...
```

**规则**：
- 引言章节必须说明「本文与已有研究的区别」
- 呼应 T4 分析大纲的「差异点声明」

## Phase 3.5 洞察补充（人在环关卡）

### 执行顺序

```
1. T5 产出 drafts/初稿-v1.md
2. 主控呈现给主人（checkpoint-card）
3. 主人决策：
   A. 无补充 → 进入 Phase 3.6
   B. 有补充 → 主控记录 → spawn T5 写手 v2 融入
```

### 为什么需要 Phase 3.5

**问题**：T5 只看到检索卡片，看不到主人脑中的「内行洞察」

**例子**：
- 主题：《家居品牌的数字化转型》
- T5 产出：基于公开文献和数据的客观分析
- 主人补充：「我在行业 10 年，看到很多公司数字化失败是因为 XXX（文献没写的实践痛点）」

**Phase 3.5 作用**：主人补充「一手洞察」→ T5 v2 融入 → 文章更有深度

### 主控呈现方式

```markdown
# Phase 3.5 洞察补充

**当前阶段**：Phase 3.5 洞察补充（人在环关卡）

**产出文件**：
- ✅ `drafts/初稿-v1.md`（已完成）

**主人决策**：

## 决策：是否补充洞察

[ ] A. 无补充，v1 已足够，进入 Phase 3.6  
[ ] B. 有补充（请在下方填写）

---

**洞察补充内容**（如选 B，请填写）：

1. **补充类型**：一手经验 / 行业内幕 / 未公开案例 / 其他
2. **补充位置**：第 X 章 第 Y 节（或「引言」「结论」）
3. **补充内容**：[主人填写]
4. **脱敏**（v2.12.46 由「可选」改为「**条件强制**」）：若补充内容涉及「行业内幕 / 未公开案例 / 内部资料 / 个人隐私」任一类型 → **必须脱敏**并在下方选择脱敏方式（① 去名 ② 改写 ③ 泛化 ④ 其他）；**默认零外发**：脱敏后内容才可进入 T5 写手输入；**未脱敏的敏感内容不得写入 `drafts/`**。

---

**请主人明确选择后，主控记录并执行。**
```

### 两种决策路径

#### A. 无补充

```
主控记录：
  status.md 更新：Phase 3.5 completed, 无补充
  
进入：Phase 3.6（spawn T6 批判；G14 已迁至 Phase 4.4 前置）

> ⚠️ 无补充仍走「退化流程」：T5 仍产 v2（实质 = v1，修订说明显式标注「主人未投喂洞察」），T6 攻击对象退化为 v1 实质。详见 [`degraded-scenarios.md`](degraded-scenarios.md)（退化条款），避免版本编号断层。
```

#### B. 有补充

```
主控记录：
  主人洞察：[记录补充内容]
  脱敏标记：[如需要]

主控 spawn T5 写手 v2：
  任务：融入主人洞察，产出 v2
  输入：
    - drafts/初稿-v1.md
    - 主人洞察（记录在 status.md 或单独文件）
  输出：
    - drafts/初稿-v2.md
    - drafts/修订说明-v2.md（说明 v1→v2 改了什么）

进入：Phase 3.6（spawn T6 批判；G14 已迁至 Phase 4.4 前置，攻击 v2 不是 v1）
```

### 「无补充」也是有效决策

**重要**：Phase 3.5「无补充」≠ 跳过。

- **跳过**：主控没有呈现 v1 给主人，直接进入 Phase 3.6 ❌
- **无补充**：主控呈现了 v1，主人看过后明确说「无补充」✅

**记录方式**：
```markdown
## Phase 3.5 洞察补充

**状态**：completed

**主人决策**：A. 无补充

**决策时间**：2024-09-08 15:30

**备注**：主人阅读 v1 后明确表示无需补充。
```

### 退化场景（可省略 Phase 3.5）

**条件**（需同时满足）：
1. 主人在 Phase 0 明确标记「紧急模式」
2. status.md 记录：`emergency_mode: true`
3. 主人在 Phase 2.5 豁免人在环

**可省略**：
- Phase 3.5 洞察补充（T5 v1 直接进入 Phase 3.6）

**风险**：
- 错过补充机会，文章深度不足
- 仅限主人明确承担风险的场景

### T6 批判伙伴（从反方攻击）

**定位**：T6 是「红队」，专门找茬。

**批判维度（C1-C7）**：
1. **C1 论证漏洞**：逻辑跳跃 / 因果倒置 / 循环论证
2. **C2 证据薄弱**：单一来源 / 🔴 低信任级别 / 时效过期
3. **C3 反方未回应**：存在明显反方观点但正文未提及
4. **C4 过度推断**：数据不支持结论
5. **C5 案例不典型**：个案当普遍规律
6. **C6 写作问题**：AI 痕迹重 / 逻辑不清
7. **C7 原创性不足**：与已有研究重复

**产出格式**：
```markdown
# 批判报告 v2

**批判目标**：drafts/初稿-v2.md（如果 Phase 3.5 有补充）

## C1 论证漏洞

### 问题 1：逻辑跳跃
**位置**：第二章 第 1 节  
**问题**：从「A 现象存在」直接跳到「B 结论成立」，中间缺少推理链。  
**建议**：补充 A→B 的中间步骤，或引用支撑文献 [Lxx]。

...

## 批判总结

**严重问题（必须修订）**：2 个  
**中等问题（建议修订）**：5 个  
**轻微问题（可选修订）**：3 个

**修订优先级**：C1 问题 1、C3 问题 2（影响核心论证）
```

## 常见问题

### Q1：主人在 Phase 3.5 说「写得不错」怎么办？

A：「不错」不是明确决策。主控必须追问：

> 「请主人明确：  
> A. 无补充，v1 已足够  
> B. 有补充（请填写补充内容）」

### Q2：T6 批判报告与 G14 的关系？

A：二者**不同阶段、不冲突**：
- T6（Phase 3.6）：论证/证据维度
- G14（Phase 4.4 前置）：AI 痕迹维度，**定稿前唯一一次**

G14 已在 Phase 3.6 之后（Phase 4.4 前置）单独运行；Phase 3.6 内**只处理 T6**。

### Q3：修订 2 轮后仍有问题怎么办？

A：按修订回环仲裁规则：
- minor 问题：T8 inline 处理
- P0/结构性 P1：呈主人拍板是否启动 v4（例外通道）

### Q4：Phase 3.5 可以跳过吗？

A：仅在紧急模式 + 主人豁免时可省略。正常模式必须走。
