## 示例项目：lunheng-v14-academic-quality-pilot

**主题**：「中国家居品牌原创设计的法律保护机制实证研究（2010-2025）」

**字数定位**：8000 字（标准档，非轻量档）

### 步骤 1：T4 分析大纲 §3.5 研究方法设计（≥300 字）

**研究设计类型**：实证研究（具体为多案例比较法 + 文本计量）。
**理由**：本文研究问题「中国家居品牌原创设计法律保护的多元化机制」涉及多个主体（品牌方 / 法院 / 行业协会 / 消费者）+ 长时段（2010-2025），单一定量或定性方法难以同时处理多主体异质性与时序演变。

**数据来源**：一手 + 二手混合
- 一手：3 个深度访谈（品牌方法务总监 / 行业协会知识产权部负责人 / 法官）
- 二手：中国裁判文书网 2010-2025 涉「家居 + 原创设计 + 知识产权」判决书（N=287，去重后 N=187）

**抽样策略**：目的性抽样 + 全样本
- 访谈对象：基于 2024 中国家居品牌 TOP 30 榜单，按「原创设计诉讼经历」分层
- 判决书：2010-2025 全样本 + 关键词过滤

**识别策略**：不适用（本研究为案例分析，非因果推断）

**分析工具**：混合方法
- 定量：判决书文本计量（关键词频次 / 诉讼请求分类编码 / 判决结果分类）
- 定性：访谈内容主题编码（Nvivo 12.0）

**局限性预估**：≤3 条
1. 判决书样本可能存在「原告选择偏差」
2. 访谈样本 N=3 不足以做统计推断
3. 时序跨度 15 年，部分早期判决书电子化质量低

### 步骤 2：T5 初稿 §4 研究方法（≥1500 字）

**§4.1 研究设计**

本文采用混合方法研究设计，结合多案例比较法与文本计量方法。研究问题聚焦于中国家居品牌原创设计的法律保护机制（2010-2025），涉及多个主体——品牌方、行业协会、法院、消费者——以及长达 15 年的时序演变过程。单纯的定量方法（如回归分析）难以捕捉主体异质性，单纯的定性方法（如单一案例深描）则难以支撑宏观判断。因此，本文选择混合方法：以多案例比较提供机制层面的解释力，以文本计量提供频次层面的描述性证据。

需要说明的是，本文**不**采用因果推断设计（无随机实验、无自然实验、无工具变量），因此因果识别策略不适用。本文的研究目标是**机制解释**与**模式描述**，而非**因果效应估计**。

**§4.2 数据**

本文数据来源为**一手 + 二手混合**：

- **一手数据**：2025 年 3-6 月进行的 3 个半结构化深度访谈
  - 访谈对象 A：某 TOP 10 家居品牌法务总监（从业 12 年）
  - 访谈对象 B：中国家居行业协会知识产权部负责人（从业 8 年）
  - 访谈对象 C：广州知识产权法院法官（审理家具类案件 7 年）
  - 抽样方法：**目的性抽样**——基于 2024 中国家居品牌 TOP 30 榜单，按「原创设计诉讼经历」分层
  - 单次访谈时长 60-90 分钟，全程录音转写

- **二手数据**：中国裁判文书网 2010-2025 年公开判决书
  - 关键词组合：「家具」「原创设计」「知识产权」（或「著作权」「外观设计」「专利」）
  - 初筛 N=287，去重 + 主体筛选 + 一审结案 后 **N=187**
  - 时间跨度：2010-01 ~ 2025-06（≈15.5 年）
  - 样本流失率：28.5%（287 → 207，经编码一致性核查后 187）

**§4.3 变量**

- **核心自变量**：品牌原创设计保护强度
  - 定义：品牌采取的法律保护行为组合（著作权登记 / 外观设计专利申请 / 商标注册 / 商业秘密协议）
  - 测量：基于访谈 + 判决书编码的 5 档李克特量表（1=无保护 / 5=全维度保护）

- **核心因变量**：原创设计被侵权后维权效果
  - 定义：诉讼请求被支持的程度
  - 测量：判决书编码的 4 档（全部支持 / 部分支持 / 驳回 / 和解撤诉）

- **控制变量清单**（≥3 项）：
  - 品牌规模（年营收区间）
  - 行业子领域（家具 / 卫浴 / 厨房 / 软装）
  - 判决时间（2010-2015 vs 2016-2020 vs 2021-2025）
  - 案件管辖地（北京 / 广东 / 江浙沪 vs 其他）

**§4.4 模型与分析方法**

本文采用**混合分析方法**：

- **定量部分**：判决书文本计量
  - 编码框架：NVivo 12.0 双人独立编码，Kappa 系数 ≥0.75
  - 描述统计：诉讼请求分类频次表 + 判决结果分布 + 跨年度趋势
  - 卡方检验：检验不同保护强度组的判决结果分布差异

- **定性部分**：访谈内容主题编码
  - 编码流程：开放编码 → 主轴编码 → 选择编码
  - 三角验证：3 个访谈对象 + 判决书样本的相互印证

**§4.5 内生性处理**

本文为案例分析方法，**不涉及内生性问题**（无因果推断）。但仍需说明以下可能偏差：
- **样本选择偏差**：维权意识强的品牌更可能起诉 → 通过多案例比较部分缓解
- **历史趋势混淆**：15 年间法律环境变化 → 通过「分段对照」部分缓解
- **报告偏差**：访谈对象可能美化自身行为 → 通过多主体三角验证部分缓解

**§4.6 局限性**

1. **样本规模有限**：N=187 判决书 + 3 个访谈，应理解为**探索性 + 模式描述**，非**因果效应估计**
2. **时序跨度长但电子化质量不均**：2010-2015 年早期判决书电子化质量低
3. **访谈样本选择偏差**：3 个访谈对象均为业内资深人士，可能代表「成功维权者」视角
4. **法律环境变化未完全控制**：15 年间法律修订可能影响判决结果，通过分段对照部分缓解，但未做正式断点回归

## 重要提示

1. **本示例仅作格式参考**：具体内容须根据项目实际填写，禁止直接复制粘贴
2. **字数严格控制**：§4 章节正文 1500-3000 字（轻量档 800 字 + 标注）
3. **G18 项 7-12 轻量档豁免**：轻量档项目仅写项 1-6 + 标 n/a + 一句豁免理由
4. **T9 D2 评分**：T9 按 D2 10 分制（研究设计 3 + 数据质量 3 + 分析严密性 2 + 可复现性 2）独立评分，与 G18 12 项对照
