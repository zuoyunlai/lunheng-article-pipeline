# 中文数据源集成（v2.5.0 新增，可选，默认关闭）

> **定位**：**中文特化补充层**，不是替代 web_search/tavily 的多语言检索——并行检索、合并去重。
> **触发**：Phase 0 定题时，主人选择「启用中文数据源集成」才激活。
> **不启用**：不影响论衡主要功能（仍用 web_search/tavily 检索中英文公开数据）。

## 一、检索架构

```
T1 文献检索（并行调用）
├── 默认层（始终启用）：web_search（OpenClaw 内置，中英文）+ tavily_search（全球化）
└── 中文层（可选启用）：知网 API / 万方 API / CSSCI 数据库
    └── 合并策略：默认层 + 中文层结果合并 → 去重（同 URL/同 DOI/同标题） → 产出文献卡

T2 数据检索（并行调用）
├── 默认层：web_search（统计数据/行业报告/新闻数据，中英文）
└── 中文层：知网/万方（中文统计/学术数据）
    └── 合并策略同上

T3 案例检索（并行调用）
├── 默认层：web_search（事件/企业/司法案件，中英文）
└── 中文层：知网/万方（中文案例）
    └── 合并策略同上
```

## 二、启用条件（Phase 0 同意关卡）

- **触发**：主人在 Phase 0 任务简报勾选「启用中文数据源集成」
- **配置**：主人需提供知网/万方/CSSCI 的 API key（通过 OpenClaw 环境变量或任务简报字段）
- **不启用**：默认层（web_search/tavily）继续跑，证据底座不变

## 三、合并策略（去重）

| 字段 | 匹配规则 |
|------|---------|
| URL | 完全相同 |
| DOI | 完全相同 |
| 标题 | 编辑距离 < 10%（防止知网和 web_search 抓的同一论文略有差异） |
| 作者+年份+期刊 | 三元组相同 |

## 四、输出格式（合并后的卡片）

文献卡/数据卡/案例卡的格式不变（v2.1.x 已定义），但在「数据源」字段标注：
```
- 来源：web_search + 知网（合并去重）
- 来源：web_search + 万方（合并去重）
- 来源：tavily_search + CSSCI（合并去重）
```

## 五、化弊为利

- **弊端**：「证据底座局限于中文」→ **不存在**，因为中文数据源是「补充」不是「替代」
- **利好**：启用后中文文献更全（知网/万方/CSSCI 的付费墙内学术论文）+ 多语言证据不受影响

## 六、Phase 0 同意关卡措辞

```
□ 启用中文数据源集成（知网/万方/CSSCI，并行补充 web_search）
  ⚠️ 需提供 API key（OpenClaw 环境变量 CNKI_API_KEY / WANFANG_API_KEY / CSSCI_API_KEY）
  ⚠️ 不启用时仍用 web_search/tavily 检索中英文公开数据，证据底座不变
```

## 七、限制

- **零 exec**：中文数据源 API 由主人在 OpenClaw 环境变量配置；论衡 agent 不直接执行 API 调用（主控 LLM 推理模拟检索流程）
- **API key 安全**：主人自管 API key，论衡不存储
- **去重质量**：依赖 DOI/标题匹配，少数情况下可能误去重
