## 二、梯队详解

### ⭐ 默认启用：真开放、无需申请、直接用

#### OpenAlex（强烈推荐）
- **性质**：全球最大免费学术元数据平台（[openalex.org](https://openalex.org)），标引 4.7 亿+ 成果
- **API**：完全免费、**无需 API Key**、REST 接口
- **中文文献覆盖**：收录大量中文学术期刊/学位论文（通过 Crossref/DOI 及中文出版商数据源）
- **能力**：按标题/作者/机构/主题/引用检索，支持全文搜索、过滤、分页
- **用法**：`GET https://api.openalex.org/works?search=人工智能&per-page=20`
- **适合**：文献计量、开题调研、引用分析

#### Crossref（强烈推荐）
- **性质**：DOI 注册机构（[api.crossref.org](https://api.crossref.org)），全球文献元数据
- **API**：免费、无 Key、REST 接口
- **能力**：按 DOI/标题/作者检索论文元数据
- **用法**：`GET https://api.crossref.org/works?query=深度学习&rows=20`
- **适合**：查 DOI、找英文文献元数据、引用格式

> **以上两者默认启用**，无需主人勾选；主人若在 Phase 0 选「④全部拒绝」则不调用。

### ❌ 已取消：原第二梯队（万方 / 科情 / NSTL）

> **本修订整体移除**，原因：**需 API Key + 申请/付费/机构门槛，长期未被使用**（主人 2026-09-11 拍板）。
> 历史信息（仅供追溯，**agent 不得据此发起任何调用**）：万方开放平台（`apps.wanfangdata.com.cn`，需付费申请）、科情数据（`smartdata.las.ac.cn`，中科院文献情报中心，需机构申请）、NSTL（`nstl.gov.cn`，面向机构图书馆）。**相关凭据自本修订起不再使用**（本文档不再列出其环境变量名）。
> **替代**：OpenAlex + Crossref 已覆盖大部分中文学术检索需求。

### 🔧 仍为可选（默认关闭）：抓取层

#### 中国科技论文在线（paper.edu.cn）
- 教育部主办，**开放存取（OA）** 平台，[paper.edu.cn](https://www.paper.edu.cn)，110 万+ 首发/期刊论文
- **没有公开 REST API** —— 可走网页抓取（Firecrawl）
- **默认关闭**；需主人 Phase 0 显式勾选 + 自配 `firecrawl_api_key`（宿主侧）
- **适合**：中文论文全文获取（检索摘要可抓，全文 PDF 直链）

#### 无公开 API 的库（说明性，不接入）
知网（CNKI）/ 维普 / 超星读秀 —— 均无公开 API（知网反爬最强）或仅面向机构图书馆，论衡**不接入**，也**不做浏览器自动化抓取**。

## 八、限制与数据流说明

- **默认层 + 中文层（OpenAlex/Crossref）= 只读公开 API，无需 Key**：通过 `web_fetch` 拉取学术元数据 JSON，**仅发送检索关键词**（主题/作者/DOI），不发送个人信息/机密数据；不要求、不存储任何 API key。
- **抓取层（Firecrawl）= 可选、默认关闭**：需主人 Phase 0 显式勾选启用；凭据由主人在宿主环境为相应外部客户端自行配置与调用，**论衡运行时不读取、不存储、不传递任何凭据值**（含宿主环境变量），未启用/未授权时对该服务零调用、零外发。
- **凭据边界**：主人自管 API key（当前仅抓取层 Firecrawl 一项需要）；论衡**不读取、不持久化、不落盘、不进 prompt、不进会话记录、不进日志、不上传第三方** —— key 仅供主人自用的宿主侧客户端读取，论衡只消费主人投喂的**不含 key** 的结果。任何角色卡的指令都不得要求把 key 值写入 prompt、卡片、状态文件或交接报告。
- **去重质量**：依赖 DOI/标题匹配，少数情况下可能误去重。
- **原第二梯队门槛（已取消，留档）**：万方/科情/NSTL 需机构付费/审批 —— 这也是本次取消的原因；OpenAlex/Crossref 足以覆盖大部分学术检索需求。
