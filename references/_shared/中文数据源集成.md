# 中文数据源集成

> **定位**：**中文特化补充层**，不是替代 web_search/tavily 的多语言检索——并行检索、合并去重。
> **触发**：Phase 0 定题时，主人选择「启用中文数据源集成」才激活。
> **不启用**：不影响论衡主要功能（仍用 web_search/tavily 检索中英文公开数据）。
> **关键修订**：原文档列「知网 API / 万方 API / CSSCI」不够准确——**知网无公开 API**、**万方需付费申请**、**CSSCI 实际无独立 API**（CSSCI 是期刊目录，不是数据库）。本修订基于主人实测分 3 梯队。
>
> **数据流声明（数据流边界）**：**默认层（web_search/tavily_search）属 Phase 0 「外部服务同意 4 选 1」告知范围**——主人选 ④全部拒绝时本次运行不调用检索工具。第一梯队 OpenAlex/Crossref 是**只读公开学术元数据 API**（无需 Key，仅发送检索关键词，**不发送个人信息/机密数据，不外发稿件正文/文献卡/数据卡内容**），**随「启用中文数据源集成」勾选后启用**（默认不用）；第二/三梯队（万方/科情/NSTL + Firecrawl）**可选、默认关闭**，需主人显式启用并自配 API key，论衡不存储 key。
>
> **下文中出现的 API URL 均为文档说明用途的示例请求形态**，不是 agent 自动执行的固定外发链路——实际调用以 Phase 0 勾选结果为准；未勾选时论衡不向这些域名发任何请求。

## 二、3 梯队详解

### 🥇 第一梯队：真开放、无需申请、直接用

#### OpenAlex ⭐（强烈推荐）
- **性质**：全球最大免费学术元数据平台（[openalex.org](https://openalex.org)），标引 4.7 亿+ 成果
- **API**：完全免费、**无需 API Key**、REST 接口
- **中文文献覆盖**：收录大量中文学术期刊/学位论文（通过 Crossref/DOI 及中文出版商数据源）
- **能力**：按标题/作者/机构/主题/引用检索，支持全文搜索、过滤、分页
- **用法**：`GET https://api.openalex.org/works?search=人工智能&per-page=20`
- **适合**：文献计量、开题调研、引用分析

#### Crossref ⭐
- **性质**：DOI 注册机构（[api.crossref.org](https://api.crossref.org)），全球文献元数据
- **API**：免费、无 Key、REST 接口
- **能力**：按 DOI/标题/作者检索论文元数据
- **用法**：`GET https://api.crossref.org/works?query=深度学习&rows=20`
- **适合**：查 DOI、找英文文献元数据、引用格式

### 🥈 第二梯队：有 API 但需申请/机构门槛

#### 万方开放平台
- [apps.wanfangdata.com.cn](https://apps.wanfangdata.com.cn/open)
- 含：文献检索、详情、全文下载、智搜（自然语言转检索语法）
- 认证：`X-Ca-AppKey` + `APPCODE`，**需付费/申请应用**
- 适合：商业级中文库

#### 科情数据（中科院文献情报中心）
- [smartdata.las.ac.cn](https://smartdata.las.ac.cn)
- 面向科研场景，数据资产级授权（非公开免费），**需机构申请审批**
- 适合：中科院体系、机构用户

#### NSTL 国家科技图书文献中心
- [nstl.gov.cn](https://www.nstl.gov.cn)
- 中文+外文文献，**面向机构/图书馆服务**，部分 OA 资源开放，API 需对接申请
- 适合：机构图书馆接入

#### 超星/读秀（备选）
- [duxiu.com](https://www.duxiu.com) — 学术搜索+原文传递，主要面向图书馆，无公开个人 API
- 适合：通过学校图书馆间接使用

### 🥉 第三梯队：无 API，靠抓取/手动

#### 中国科技论文在线（paper.edu.cn）
- 教育部主办，**开放存取（OA）** 平台，[paper.edu.cn](https://www.paper.edu.cn)，110 万+ 首发/期刊论文
- **没有公开 REST API**——可走网页抓取（Firecrawl）
- **适合**：中文论文全文获取（检索摘要可抓，全文 PDF 直链）

#### 知网（CNKI）
- **无公开 API**、反爬最强 → 只能浏览器自动化（之前实战验证过） 或机构渠道

#### 维普
- 类似知网，无公开 API，机构订阅为主

> **v2.5.0 → v2.5.1 关键修正**：原文档写「知网/万方/CSSCI」——知网无公开 API（需浏览器自动化）、CSSCI 不是数据库（是期刊目录）、万方需付费申请。v2.5.1 改为 **OpenAlex + Crossref 第一梯队（默认推荐）** + 万方/科情/NSTL 第二梯队（需申请）+ paper.edu.cn 第三梯队（抓取）。

## 三、启用条件（Phase 0 同意关卡）

- **触发**：主人在 Phase 0 任务简报勾选「启用中文数据源集成」
- **默认推荐（无需配置）**：OpenAlex + Crossref（第一梯队，**勾选「启用中文数据源集成」后自动启用**；未勾选则只用默认层）
- **需 API key 配置**（主人 Phase 0 选二梯队时）：凭据由主人**在论衡运行环境之外**为相应客户端/服务自行配置（宿主环境变量或本地凭据文件，仅供主人自用的外部工具读取），**论衡 agent 不读取、不存储、不传递任何凭据值**，只消费主人投喂的**不含凭据**的检索结果：
  - 万方：`WANFANG_APP_KEY` + `WANFANG_APPCODE`
  - 科情数据：`KQING_APP_KEY`（机构申请后）
  - NSTL：`NSTL_APP_KEY`（机构申请后）
- **抓取层**：paper.edu.cn 如需 Firecrawl 抓取，凭据由主人自行在宿主侧为 Firecrawl 客户端配置；**本技能不读取 `firecrawl_api_key` 等任何凭据值**，只消费抓取结果
- **不启用**：默认层（web_search/tavily）继续跑，证据底座不变

## 四、合并策略（去重）

|------|---------|

## 八、限制与数据流说明

- **第一梯队（OpenAlex/Crossref）= 只读公开 API，无需 Key**：通过 `web_fetch` 拉取学术元数据 JSON，**仅发送检索关键词**（主题/作者/DOI），不发送个人信息/机密数据；不要求、不存储任何 API key。
- **第二/三梯队（万方/科情/NSTL API + Firecrawl）= 可选、默认关闭**：需主人 Phase 0 显式勾选启用；凭据由主人在宿主环境为相应外部客户端自行配置与调用，**论衡运行时不读取、不存储、不传递任何凭据值**（含宿主环境变量），未启用/未授权时对这些服务零调用、零外发。
- **凭据边界**：主人自管 API key；论衡**不读取、不持久化、不落盘、不进 prompt、不进会话记录、不进日志、不上传第三方**——key 仅供主人自用的宿主侧客户端读取，论衡只消费主人投喂的**不含 key** 的结果。任何角色卡的指令都不得要求把 key 值写入 prompt、卡片、状态文件或交接报告；本文档出现环境变量名仅为告知主人需为哪些外部服务配置凭据，**不代表论衡可读取其值**
- **去重质量**：依赖 DOI/标题匹配，少数情况下可能误去重
- **第二梯队门槛**：万方/科情/NSTL 需机构付费/审批，第一梯队（OpenAlex/Crossref）足以覆盖大部分学术检索需求
