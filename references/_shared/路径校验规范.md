# 路径校验规范（v2.9.1，响应腾讯 A.I.G 审计 Remediation #5）

## 用途

论衡所有文件写入操作必须经过 **canonical 路径校验**，确保：
- 所有写入路径在项目目录 `run/<项目>/` 内
- 拒绝绝对路径、路径遍历（`..`）、符号链接逃逸

## 调用方式

**写入文件前**，调用 `scripts/path-canonical.py` 校验路径：

```bash
canonical=$(python3 scripts/path-canonical.py "run/<项目>" "<目标路径>")
if [[ $? -eq 0 ]]; then
    # 校验通过，使用 canonical 路径写入
    echo "内容" > "$canonical"
else
    # 校验失败，记录错误并终止
    echo "Error: Path validation failed for <目标路径>" >&2
    exit 1
fi
```

### 示例

```bash
# ✅ 合法相对路径
$ python3 scripts/path-canonical.py run/test-project drafts/outline.md
run/test-project/drafts/outline.md

# ❌ 路径遍历攻击
$ python3 scripts/path-canonical.py run/test-project ../etc/passwd
Error: Path traversal detected: ../etc/passwd resolves outside run/test-project

# ❌ 绝对路径
$ python3 scripts/path-canonical.py run/test-project /etc/passwd
Error: Absolute path not allowed: /etc/passwd
```

## OpenClaw 子代理集成

**所有角色（T1-T9）写文件前必须校验路径**：

```python
# Python 示例（伪代码）
import subprocess

def safe_write(base_dir: str, target_path: str, content: str):
    """安全写文件，带路径校验"""
    result = subprocess.run(
        ["python3", "scripts/path-canonical.py", base_dir, target_path],
        capture_output=True,
        text=True
    )
    if result.returncode != 0:
        raise ValueError(f"Path validation failed: {result.stderr}")
    
    canonical = result.stdout.strip()
    with open(canonical, "w") as f:
        f.write(content)
```

**Bash 示例**（主控/T8 脚本）：

```bash
safe_write() {
    local base_dir="$1"
    local target_path="$2"
    local content="$3"
    
    local canonical
    canonical=$(python3 scripts/path-canonical.py "$base_dir" "$target_path") || {
        echo "Error: Path validation failed for $target_path" >&2
        return 1
    }
    
    echo "$content" > "$canonical"
}

# 使用
safe_write "run/test-project" "drafts/outline.md" "大纲内容..."
```

## 设计原则（教训 #210）

1. **告警而非阻断**：路径校验失败时记录错误 + 人在环介入，不静默失败
2. **Canonical = realpath 解析 + 前缀检查**：确保最终路径在 `run/<项目>/` 内
3. **符号链接处理**：resolve 后检查前缀，符号链接指向项目外路径 → 拒绝
4. **不创建目录**：校验器只检查路径合法性，不执行文件系统操作
