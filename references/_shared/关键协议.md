### 叶子纪律（子代理不再委托，v2.12.8 新增）

**背景**：OpenClaw 自 2026.9.3 起**默认开启有界递归委派**（`maxSpawnDepth` 默认 5）——depth < cap 的子代理确实拿到 `sessions_spawn` / `subagents` / `sessions_list` / `sessions_history`。论衡架构假设「角色卡 = 叶子 worker」（主控只等**直接**子级；announce 链逐级上传），故必须显式锁叶。

**规则（所有非主控角色适用）**：
- **不得**调用 `sessions_spawn` 派生任何子代理——需要额外检索/额外人手时，在**交接报告**写「需求回执」（缺什么、为什么缺、建议派谁），由主控决定是否 spawn
- **不得**调用 `subagents` / `sessions_list` / `sessions_history` 查看或管理其他会话（该能力属主控；叶子拿到是平台默认，不是授权）
- 子代理之间**不直接通信**（不调 `sessions_send`）——回传路径只有「交接报告 → 主控」一条
- 「未被平台剥夺」≠「被授权」：遵论衡纪律层，不因工具可得而扩大行为面

**三层冗余落地**（机械层优先，纪律层兑付）：
| 层 | 位置 | 宿主需做 |
|---|---|---|
| 机械 | `agents.defaults.subagents.maxSpawnDepth: 1` | 宿主 config（hot reload）——直接子代理即叶子 |
| 纪律·角色卡 | `agents/0X-*.md` 头部声明 | 无（已内置）|
| 纪律·任务书 | 主控每次 spawn 必含叶子声明（见 `00-主控-扩展职责.md` §三）| 无（已内置）|

**代价（为何必须锁）**：子代理自行再 spawn 时，孙辈完成事件**不上传到主控**（announce 链逐级上传，主控只收直接子级）——主控看不到孙辈产物，等于「产出静默丢失 + token 已花」。

### 修订回环 ≤2 轮降级（教训 #270，+ #276）
**规则**：
- **「轮」的定义**（单一真源 = SKILL.md「修订回环仲裁规则」）：0 轮=T5 出 v1；1 轮=v1→v2（Phase 3.5 洞察 + T6/G14 批判反馈融入）；2 轮=v2→v3（T7 审计打回 / G14 Warning+ 修订，或 T8 亲修）；minor 修补（≤5% 字 / 引用格式 / 拼写 / 元叙事清理 / P1-D 事实错误）走 T8 inline 独立通道**不计轮**；超 2 轮 = 结构性 P1（A/B/C）+ P0 → spawn T5 v4 + Acknowledged Limitations（例外通道，须主人拍板）
- **T8 小幅修补权限**：≤字数 5% / AI 披露修正 / 元叙事清理 / P1-D 事实错误 → T8 亲修；结构性 P1-A/B/C + P0 → T5 独立写手
- **P1 分级**：P1-A/B/C（论证补强/结构缺失/反方缺失）→ T5 重启；P1-D（引用格式/元数据/漏引/拼写）→ T8 亲修
- 第 3 轮：自动降级为"人工介入模式"（Acknowledged Limitations）

**降级原因**：
- 防止无限循环（教训 #270）
- 强制人工决策介入（主人判断是否继续/终止/调整方向）

### 执行韧化协议
**四层防御**：

1. **心跳机制**：每 30 秒一次心跳 ACK
2. **分阶段 ACK**（3 档）：
   - 短任务（<3 分钟）：不需要
   - 中任务（3-8 分钟）：1 次中途 ACK
   - 长任务（>8 分钟）：多次 ACK
3. **LLM 可用性初判**：子代理观察首次 LLM 调用响应与首 token 延迟；30s 无首响应 → 降级 fallback
4. **超时硬卡（角色分级）**：阈值见主控扩展职责 §二十二（T1-T3 10 / T4 12 / T5 15 / T6 15 / T7 12 / T9 10 / G14 8 分钟）

**Fallback 链**：主模型 30s 无响应时的降级次序由**宿主 agent 的 `model.fallbacks` 配置**决定（宿主维护项，论衡文档不绑定具体模型 ID；映射方法见 [`模型候选池.md`](模型候选池.md)）——子代理感知的行为：主模型静默 → 宿主自动切下一档，角色在产物头部标注降级事实
