## 重写说明（教训 #166）

**为什么重写**：
- 原 markdown 表格（7 列） + 主控 edit 频繁失败（空格漂移 / old_string 不匹配 / 重复行 bug）

**怎么改**：
- 角色状态从「表格行替换」改为「key:value 文本替换」 → `**T5 写作**: ⬜ Inbox` → `**T5 写作**: ✅ Done` （一行一替换，零空格漂移）

- 产物路径从「表格行」改为「key:value」（路径在项目内不变）
- 方法论足迹从「表格」保留表格（实时数据有数字变化，主控用 row replace）
