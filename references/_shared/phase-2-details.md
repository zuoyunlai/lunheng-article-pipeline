## Phase 2 分析（T4 分析员）

### 执行顺序

```
主控 spawn T4 分析员：
输入：
  - 01-任务简报.md（主题/子问题/字数预算）
  - literature/文献卡.md（[Lxx] 8-12 条）
  - data/数据卡.md（[Dxx] 30-50 条）
  - cases/案例卡.md（[Cxx] 5-8 条或空卡）

输出：
  - analysis/分析大纲.md
```

### 分析大纲必备要素

#### 1. 论证主线

```markdown
## 论证主线

### 核心论点
[一句话：本文的中心论点是什么]

### 论证路径
1. 引言：提出问题
2. 第一章：XXX（支撑论点 A）
3. 第二章：XXX（支撑论点 B）
4. 第三章：XXX（支撑论点 C）
5. 结论：回应核心论点
```

#### 2. 论点-论据映射表

```markdown
## 论点-论据映射

| 论点 | 支撑文献 | 支撑数据 | 支撑案例 | 完整度 |
|------|---------|---------|---------|--------|
| A. XXX | [L01][L03] | [D05][D12] | [C01] | ✅ 三角齐全 |
| B. XXX | [L05] | [D20][D25] | 无 | ⚠️ 缺案例（理论论证，可接受） |
| C. XXX | [L08][L09] | 无 | [C03][C04] | ⚠️ 缺数据（需说明原因） |
```

**完整度判定**：
- ✅ 三角齐全：文献 + 数据 + 案例
- ⚠️ 两项齐全：需在「论证策略」中说明为何缺某项
- ❌ 只有一项：必须补检索或调整论点

#### 3. 反方论证规划

```markdown
## 反方论证

### 可能的反驳

#### 反驳 1：XXX
**反方观点**：[举例：「有人认为 XXX」]  
**反方依据**：[如果有文献/数据支持反方，列出]  
**本文回应策略**：
- 承认合理部分：[举例]
- 指出局限：[举例]
- 提供更强证据：[引用 [Lxx]/[Dxx]/[Cxx]]

#### 反驳 2：XXX
...
```

**为什么需要反方论证**：
- 避免单边叙事
- 提升论证深度
- T6 批判伙伴会从反方攻击，提前准备能减少修订轮次

#### 4. 三角验证清单

```markdown
## 三角验证清单

### 核心论点的证据支撑

- [ ] 论点 A：文献 [L01][L03] + 数据 [D05][D12] + 案例 [C01] ✅
- [ ] 论点 B：文献 [L05] + 数据 [D20][D25] + 案例 无 ⚠️
- [ ] 论点 C：文献 [L08][L09] + 数据 无 + 案例 [C03][C04] ⚠️

### 证据缺口说明
- 论点 B 缺案例：理论论证，不涉及企业行为，可接受
- 论点 C 缺数据：该领域暂无量化研究，依赖案例归纳
```

#### 5. 章节字数预算

```markdown
## 章节字数预算

**总字数目标**：5000 字（任务简报指定）

| 章节 | 预算字数 | 占比 |
|------|---------|------|
| 引言 | 500 | 10% |
| 第一章 XXX | 1200 | 24% |
| 第二章 XXX | 1500 | 30% |
| 第三章 XXX | 1200 | 24% |
| 结论 | 600 | 12% |
| **合计** | **5000** | **100%** |
```

**预算原则**：
- 核心章节占比最高（25-35%）
- 引言 10-15%，结论 10-15%
- 留 5-10% 弹性空间

#### 6. 建议图表（Phase 2.5 拍板）

```markdown
## 建议图表

### 图表 1：XXX 趋势图
**类型**：折线图  
**数据源**：[D05][D12]  
**位置**：第一章 第 2 节  
**目的**：展示 XXX 变化趋势

### 图表 2：XXX 对比
**类型**：柱状图  
**数据源**：[D20][D25]  
**位置**：第二章 第 1 节  
**目的**：对比 A 与 B 的差异

...
```

**重要**：图表建议由 T4 提出，**Phase 2.5 由主人拍板**（数量/类型/位置）

#### 7. 本文与已有研究的差异

```markdown
## 本文与已有研究的差异

**已有研究**：
- [先行者 1]：XXX（发表于 YYYY）
- [先行者 2]：XXX（发表于 YYYY）

**本文差异点**：
1. **角度创新**：已有研究从 XXX 角度，本文从 YYY 角度
2. **数据更新**：已有研究用 YYYY 年数据，本文用 ZZZZ 年数据
3. **方法改进**：已有研究用 XXX 方法，本文用 YYY 方法
4. **结论突破**：已有研究认为 XXX，本文发现 YYY
```

**G7 原创性审计**会检查这一节，必须清晰且有实质内容。

## Phase 2.5 大纲确认（人在环关卡）

### 为什么不可跳过

**Phase 2.5 是改方向成本最低的节点**：

- 大纲阶段调整：重新组织论证路径，成本低
- 初稿阶段调整：重写整章，成本高 10 倍
- 定稿阶段调整：推倒重来，成本高 50 倍

### 主控呈现方式

```markdown
# Phase 2.5 大纲确认

**当前阶段**：Phase 2.5 大纲确认（人在环关卡）

**产出文件**：
- ✅ `analysis/分析大纲.md`（已完成）

**主人决策点**：

## 决策 1：论证路径
[ ] A. 认可当前大纲，进入 Phase 3 写作  
[ ] B. 需要调整论证路径（请说明调整方向）  
[ ] C. 需要补充检索（请说明缺口）  
[ ] D. 重新定题（重大方向调整，返回 Phase 0）

## 决策 2：图表拍板
T4 建议 [N] 个图表：
- 图表 1：XXX 趋势图（折线图，数据源 [D05][D12]）
- 图表 2：XXX 对比（柱状图，数据源 [D20][D25]）
- ...

[ ] A. 全部采纳  
[ ] B. 部分采纳（请勾选保留哪些）  
[ ] C. 全部取消（纯文字论文）  
[ ] D. 调整图表类型/位置（请说明）

**请主人明确选择后，主控记录决策并进入下一阶段。**
```

### 四种决策路径

#### A. 认可当前大纲

```
主控记录：
  status.md 更新：Phase 2.5 completed, 主人认可
  graph_approval: 图表 [1, 2, 3] 已拍板

进入：Phase 3 写作（spawn T5）
```

#### B. 需要调整论证路径

```
主控记录：
  主人反馈：[记录调整方向]
  
主控 spawn T4b（修订大纲）：
  任务：按主人反馈调整论证路径
  输出：analysis/分析大纲-revised.md

重新进入 Phase 2.5 确认
```

#### C. 需要补充检索

```
主控记录：
  主人反馈：[记录缺口]

主控 spawn T1b/T2b/T3b（补充检索）：
  任务：补充 [Lxx]/[Dxx]/[Cxx]
  输出：更新对应卡片文件

主控 spawn T4b（重新分析）：
  任务：整合新证据，重新产出大纲

重新进入 Phase 2.5 确认
```

#### D. 重新定题

```
主控记录：
  主人反馈：[记录重大调整]
  status.md 更新：Phase 2.5 rejected, 返回 Phase 0

返回：Phase 0 定题
```

### 无明确决策 = 未通过

**重要**：主人未明确选择 A/B/C/D，主控不得推进。

错误做法：
```
❌ 主人：「大纲不错」  
   主控：「好的，进入 Phase 3」  
   → 「不错」不是明确决策，可能只是客套
```

正确做法：
```
✅ 主控：「请主人明确选择 A/B/C/D」  
   主人：「选 A，认可当前大纲」  
   主控：「收到，进入 Phase 3」
```

## 退化场景（Phase 2.5 例外通道）

### 轻量档（<3000 字）

**条件**：
- 字数 < 3000 字
- 主题简单（单一论点）
- 主人明确要求「快速产出」

**可省略**：
- 反方论证规划（简化为一句话提及）
- 章节字数预算（T5 自由发挥）
- 建议图表（纯文字输出）

**仍然必须**：
- 论点-论据映射表
- 三角验证清单
- 本文与已有研究的差异

### 紧急模式（主人豁免）

**条件**：
- 主人在 Phase 0 明确标记「紧急模式」
- status.md 记录：`emergency_mode: true`

**可省略**：
- Phase 2.5 人在环（T4 直接交给 T5，主控在 Phase 3.5 补确认）

**风险**：
- 方向错误时，修订成本高
- 仅限主人明确承担风险的场景

## 常见问题

### Q1：主人说「随便写吧」怎么办？

A：「随便」不是明确决策。主控必须追问：

> 「请主人明确：  
> A. 认可当前大纲，进入写作  
> B. 需要调整（请说明方向）  
> 没有明确选择，流程无法推进。」

### Q2：T4 产出的大纲太粗糙怎么办？

A：主控在 Phase 2.5 检查大纲完整性：

- 缺必备要素 → 主控不呈现给主人，先让 T4 补完
- 完整但粗糙 → 呈现给主人，由主人决策是否接受

### Q3：主人在 Phase 2.5 提出重大新方向怎么办？

A：判断是「调整」还是「重新定题」：

- **调整**：论证路径变化，但核心论点不变 → 选 B（spawn T4b）
- **重新定题**：核心论点变化 → 选 D（返回 Phase 0）

判断标准：
> 「Phase 1 检索的证据还能用吗？」  
> 能用 → 调整  
> 不能用 → 重新定题
