## 三、和「直接让一个 AI 写论文」的区别

### 单 AI 写论文的痛点

- ❌ 自我审视 = 自我说服（LLM 舒适区陷阱）
- ❌ 引用 / 数据 / 案例 全部由同一人编造（无证据底座）
- ❌ 反方论证走过场（同一个 LLM 难以真正反对自己）
- ❌ 修订后无法定位改动（没有阶段状态机）

### 论衡的解决方案

| 痛点 | 解决方案 |
|------|---------|
| 自我审视 = 自我说服 | **10 张角色卡（T0-T7 + T8 终检 + T9）+ T7 审计独立判定** |
| 引用 / 数据 / 案例 凭空 | **三角验证 [L]+[D]+[C]** + **M 门机械化校验** |
| 反方论证走过场 | **T6 批判伙伴独立攻击 C1-C7** |
| 修订后无法定位 | **status.md 状态机 + Phase 0-5 6 个闸门** |
| 过程语言残留 | **M-Form-5 grep 自检 + 元数据边界铁律 #8** |
| 数据信任不明 | **3 档信任级别（已发布/主人投喂/二手转引）** |
| 失败模式无结构化防御 | **F1-F9 失败模式清单（ARS Lu et al. *Nature* 2026 论衡化）** |
| 字数口径歧义（T7/T8 不一致） | **v2.4.6 双口径统一核验**（纯汉字 + 含文末四节，分级 ≤1% P2 / 1-5% P1 / >5% P0，见 `_shared/真源/字数判定表.md`） |
| T8 代写越界 | **v2.4.6 字数超限红线**：超限 → spawn T5 v3 精简，主控只核验不 edit（防代写+字数越改越超） |
| 退化解耦：跳过 Phase 3.5 | **v2.4.6 退化场景规范**（攻击对象退化为 v1、T5 v2 标注「主人未投喂洞察」；轮次计入 → 见 `_shared/真源/pipeline-overview.md`『修订回环仲裁规则』） |
| 大模型 token 消耗大（73 条 5 万字） | **v2.5.0 素材按需加载**：T4/T5 按论点-论据映射表定位条目，只读相关不读全文 |
| 中文期刊匹配缺 | **v2.5.0 期刊匹配助手**：T9 评审后自动匹配 24 中文 CSSCI + 12 英文 SSCI 数据库（学术模式默认开启） |
| 中文证据底座局限 | **中文数据源集成**（**OpenAlex/Crossref 默认关闭、Phase 0 勾选启用**，无需 Key，与 web_search/tavily 并行补充——启用后中文文献更全 + 多语言证据不受影响） |
| Markdown 转 Word/PDF | **不属 Phase 0 选项**（主人裁定 2026-09-18）：格式转换（md/latex/docx/pdf）下沉到 T8 终检后的「主人自行操作建议清单」（命令模板 + 执行者 = 主人 host shell，agent 不执行） |

**论衡哲学**：「独立角色 + 机械化门 > 自我复核」
